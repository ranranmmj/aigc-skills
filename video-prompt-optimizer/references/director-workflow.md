# 导演工作流（多镜项目）

> 模型无关。用于 40–120 秒短片、整集短剧、多镜广告。
> 定位：写提示词前的“结构与资产检查”，不是项目管理系统。

## 1. 什么时候用

- 一条片子超过 3 个镜头。
- 需要跨镜一致性（人物/场景/道具/光线）。
- 需要先定视觉规范，再逐镜写提示词。
- 需要给客户/导演看分镜表，而不是直接跑模型。

单镜、简单需求不需要走完整流程；直接用场景配方 + 模型方言。

## 2. 七阶段（压缩版）

| 阶段 | 任务 | 产出 | 暂停点 |
|---|---|---|---|
| 1 立项 | 用途、时长、主题、受众、核心价值 | 一句话 brief | ✅ 目标/受众确认 |
| 2 创意 | 3 个方向、故事结构、剧本 | 创意方案 + 剧本 | ✅ 方向三选一 |
| 3 视觉 | 视觉定调、色卡、光影、画风 | Visual Bible | ✅ 定调确认 |
| 4 资产 | 人物/场景/道具/特效 | 资产库 | ❌ 缺了再补 |
| 5 分镜 | 镜头表、故事板 | 分镜脚本 | ✅ 结构 gate |
| 6 生成 | 逐镜提示词、生成、初筛 | 镜头素材 | ✅ 分批暂停（每批 3–5 镜） |
| 7 后期 | 剪辑、音频、调色、字幕、交付 | 成片 | ✅ 成片 gate |

暂停话术（固定句式）：

> 下一步我会<做什么>；需要你确认<什么>。回「通过 / 修改 / 自检」即可。

用户说“直接给 / 不用确认”时跳过，并在交付说明里注明跳过了哪个节点。

口诀：**立方案 → 搭资产 → 画分镜 → 生视频 → 做音频 → 剪片子 → 交成片。**

## 3. Visual Bible

任何多镜项目先锁一份全片规范：

| 项 | 要写什么 |
|---|---|
| 视觉定位 | 写实/动画/国风/赛博/甜宠/暗黑；一句话 |
| 时代/地域 | 古代/现代/未来；城市/山林/宗门 |
| 美术风格 | 参考作品 + 关键词 + 禁止项 |
| 色彩 | 主色/辅色/情绪色；HEX/RGB 更好 |
| 光影 | 主光方向、色温、对比、风格（伦勃朗/平光/硬光） |
| 摄影 | 机位、焦段、景深、画幅、画质、颗粒 |
| 材质 | 皮肤/布料/金属/石材/特效的统一质感 |
| 情绪 | 全片情绪曲线与关键词 |
| 画幅 | 16:9 / 9:16 / 2.39:1 |
| 禁止 | 现代元素、塑料 CG、过度美颜、字幕水印等 |

固定前缀示例：

```text
竖屏 9:16，电影级写实，低饱和冷灰色调，ARRI 色彩科学，
浅景深，真实皮肤纹理与胶片颗粒，冷峻压抑的东方剑道玄幻氛围。
```

## 4. 镜头表字段

每个镜头至少写：

```text
镜号：
场次：
时间（起-止）：
时长：
景别：
角度：
运镜：
焦段：
光影：
镜头目的：建立/制造冲突/展示关系/揭露秘密/制造悬念
画面内容：
人物动作：
表演/微表情：
台词（情绪）：
音效：
特效：
负面控制：
参考素材：
```

要求：

- **镜头目的**必须写；没有目的的镜头删掉。
- 每个镜头只承担一个主要功能。
- 多镜之间写清“上一镜结束状态 = 下一镜开始状态”。
- 转场写清方式（硬切/叠化/甩镜/匹配剪辑）。
- 字段以本表为准；用 `assets/shot-sheet-template.md` 或场景配方里的简表时，至少补齐“镜头目的 / 参考素材 / 时间（起-止）”三列。

## 5. 生成单元（多镜合一生）

AI 生成常把多条成片镜头放进一次生成（生成 4–30 秒视频，再剪辑拆成多条短镜头）。这时真正的单位是**生成单元**，不是单个 CUT。

**分组规则**

- 同一空间、同一方向、动作连续 → 可合一个单元；
- 正反打（机位相反）、跨空间、景别硬切、影调突变 → 拆单元；
- 单元内只能有一条连续机位路径（推/拉/移/跟/固定）；**不要把一个单元写成两个独立机位**。

**单元字段**

```text
单元号：
包含 CUT：
单元时长：
单元内机位路径：
信息层数：
可切点：
单元内时间控制方式：
```

**容量**

- 单元时长 = 各 CUT 成片时长之和 + 转场余量；
- 信息层数按 `timing-and-beats.md` 算，不要超；
- 单单元建议 6–12 秒，15–20 秒为上限；超过 20 秒连贯性明显下降，超过 30 秒要先拆；
- 单元内按命中模型的时间控制机制切段（见各自方言），不要混用。

**可切点**

- 切点放在动作重新起势处、句号处或静默处，不要切在动作中段；
- 切点也可以承担叙事功能——把中间动作藏起来（先给结果、再揭示），就是“反应前置型”。

## 6. 节奏模型

### 6.1 双轨节奏（先标两条线）

每场戏先标两轨，不要只标一条：

- **情节轨**：松 / 紧 —— 事件推进速度、冲突强度。
- **情感轨**：轻 / 重 —— 人物情绪重量、观众共情强度。

两轨不必同步：情节紧、情感轻（打斗），或情节松、情感重（沉默对峙），都是有效节奏。

### 6.2 三层叠加

把三层叠在一张表上，不要只写时长：

1. 情节轨（松紧）
2. 情感轨（轻重）
3. 导演执行层：镜头密度（镜/10 秒）、景别重心（远/中/近/特）、转场策略

### 6.3 节奏波浪（示意）

```text
强度
高 │        ██        ████
中 │   ██  ████  ██  ██████
低 │ ███████████████████████
   └────────────────────────▶ 时间
     钩子  建立  升级  转折  高潮  落点
```

检查：全片是否有至少两处“高—低”落差？一条直线就是没有节奏。

### 6.4 四块常用模板

- **40 秒**：0–5 钩子 / 5–25 展开 / 25–35 高潮 / 35–40 落点。
- **60 秒**：0–3 钩子 / 3–15 建立 / 15–35 升级 / 35–45 转折 / 45–55 高潮 / 55–60 悬念。
- **90–120 秒**：建立 → 升级 → 转折 → 高潮 → 余味。
- **30 秒动作**：10 镜 × 3 秒；每秒一个动作节拍（见 `scenario-action.md`）。

## 7. 评审与评分

满分 100：

| 项 | 分值 | 看什么 |
|---|---|---|
| 故事性 | 25 | 主题、冲突、变化 |
| 情绪价值 | 25 | 共鸣、记忆点 |
| 视觉创造力 | 20 | 视觉符号、世界观 |
| 镜头语言 | 15 | 电影感、节奏 |
| AI 执行 | 15 | 一致性、可实现性 |

多角色审稿：

- **编剧**：故事成立吗？冲突够吗？
- **导演**：镜头高级吗？有电影感吗？
- **美术**：世界独特吗？视觉统一吗？
- **观众**：前 10 秒抓人吗？结尾有记忆吗？

低于 70 分先改结构，不要靠堆特效。

## 8. 交给提示词层

1. 先定 Visual Bible 与镜头表。
2. 按场景配方（TVC/短剧/动作/情绪/蒙太奇）写段落结构。
3. 按 `visual-language.md` 写景别/角度/运镜/色彩。
4. 按 `consistency-and-assets.md` 检查资产与跨镜锚点。
5. 最后读模型方言，逐镜翻译成模型语法。
6. 多镜项目不要把所有镜头塞进一条提示词；逐镜/分段生成，后期剪。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 全片风格不统一 | 没有 Visual Bible | 先锁画风/色卡/光影/相机 |
| 镜头没有目的 | 为好看而拍 | 每个镜头写目的；删无功能镜头 |
| 跨镜跳变 | 上一镜结束 ≠ 下一镜开始 | 写结束状态；复用空间锚点 |
| 节奏拖 | 镜头太长/信息重复 | 3–5 秒/镜；删重复；加钩子 |
| 情绪不落 | 只有事件 | 加反应镜头/空镜/母题 |
| 资产不够 | 边写边找图 | 先建资产库再写分镜 |
| 生成不可控 | 镜头太大/太复杂 | 拆镜；一镜一动作；先小样 |
