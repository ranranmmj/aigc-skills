# 蒙太奇 / 节奏场景

> 模型无关。先定镜头之间的关系，再落到模型方言。
> 核心：**蒙太奇不是“把镜头接起来”，而是“让镜头并置后产生单个镜头没有的意义”。**

## 1. 先问清楚

| 问题 | 要拿到什么 |
|---|---|
| 要讲什么故事 | 情节线、人物目标、结局 |
| 要表达什么情绪/观点 | 主题、隐喻、对比 |
| 有几条线 | 一条 / 两条 / 多条；各自时空 |
| 线之间什么关系 | 因果（交叉）/ 并置（平行）/ 重复母题 / 回忆 |
| 时长 | 40 / 60 / 90–120 秒 |
| 母题 | 反复出现的物件/动作/颜色/声音 |
| 空镜 | 开场/情绪/转场；每个空镜的功能 |

## 2. 两种基本类型

| 类型 | 核心问题 | 功能 |
|---|---|---|
| 叙事蒙太奇 | 怎么讲故事、怎么组织时空 | 推进情节、压缩时间、建立因果、制造悬念 |
| 表现蒙太奇 | 怎么表达情绪、思想、隐喻 | 情绪冲击、隐喻、心理、观点 |

一句话：叙事让你“看懂”，表现让你“感受到”。

## 3. 叙事蒙太奇

### 平行蒙太奇

- 两条或以上情节线并行，分别叙事，最后统一在一个结构里。
- 可以是同一时间，也可以是不同时间。
- 线之间**没有因果**，靠主题并置产生意义。
- 作用：扩大信息量、宿命感、因果关联、跨时空回响。
- 判断：删掉 A 线，B 线结局**不变** → 平行。

示例：骗子开香槟庆功 / 受害者跳楼；两条线互不知道，并置产生道德冲击。

### 交叉蒙太奇

- 同一时间多条线齐头并进，相互有因果，交替频繁，最终汇合。
- 作用：紧张、悬念、冲突尖锐化。
- 判断：删掉 A 线，B 线结局**改变** → 交叉。

示例：追杀与逃跑交替；拆弹与倒计时交替。

### 连续蒙太奇

- 单一情节线，按事件逻辑顺序，有节奏地连续叙事。
- 作用：自然、流畅、易跟随。
- 长片中很少单独使用，多与平行/交叉混用。

### 重复蒙太奇

- 有寓意的镜头在关键时刻反复出现，相当于文学复叙。
- 作用：刻画人物、深化主题、制造回响。
- 写法：同一物件/动作/颜色/声音，每次出现推进一层含义。

### 颠倒蒙太奇

- 打乱时间顺序，先现在再过去，或过去/现在交错。
- 常借叠化、划变、画外音转入倒叙。
- 作用：悬念、因果揭示、命运感。

## 4. 表现蒙太奇

### 隐喻蒙太奇

- 用具体画面表达抽象情感；通过类比让观众联想。
- 例：笼中鸟 ↔ 被囚禁的人；枯萎的花 ↔ 逝去的爱情。

### 对比蒙太奇

- 内容或形式强烈对比：贫/富、生/死、战争/和平、冷/暖、大/小。
- 作用：强化反差、突出主题、制造张力。
- 例：宴会厅 ↔ 街头流浪汉；昔日辉煌 ↔ 今日落魄。

### 心理蒙太奇

- 表现梦境、回忆、闪念、幻觉、思考。
- 外部事件触发心理事件；回忆不是交代前史，而是让观众进入人物此刻情绪。
- 长度：几秒到十几秒；不要长篇回忆。

### 抒情蒙太奇

- 在叙事连贯中切入象征情绪的镜头，创造意境。
- 例：叙事段落之后切雨后的街道、飘落的树叶、渐暗天色。
- 作用：渲染情绪、营造氛围、让观众沉浸。

## 5. 镜头之间怎么产生意义

写提示词/分镜时，不要只写“镜头 1、镜头 2、镜头 3”，要写**关系**：

| 关系 | 写法 |
|---|---|
| 因果 | A 的动作导致 B 的结果；用同一物件/同一动作连接 |
| 并置 | A 与 B 主题相同、时空不同；用相同构图/颜色/声音呼应 |
| 对比 | A 与 B 内容或形式相反；用冷暖/大小/动静对比 |
| 重复 | 同一母题第 1/2/3 次出现，含义递进 |
| 心理 | 外部事件 → 闪回/幻觉 → 回到现实 |
| 抒情 | 叙事段落后切入空镜/环境，情绪落点 |

## 6. 节奏模型

### 40 秒

```text
0–5s   视觉钩子
5–25s  事件展开
25–35s 情绪高潮
35–40s 主题落点
```

### 60 秒

```text
开场 → 人物 → 冲突 → 转折 → 高潮 → 结尾
```

### 90–120 秒

用微电影结构：建立 → 升级 → 转折 → 高潮 → 余味。

### 30 秒动作

10 镜 × 3 秒；每秒一个动作节拍（详见 `scenario-action.md`）。

## 7. 空镜

空镜必须承担功能，不要凑数：

| 功能 | 时长 | 内容 |
|---|---|---|
| 开场交代 | 1–2s | 时间、地点、环境氛围 |
| 情绪留白 | 2–3s | 关键台词/事件后，让观众消化 |
| 转场衔接 | 1s | 两场戏之间，自然过渡 |

空镜内容要与剧情强相关：用道具、环境、天气替代人物表达情绪。不要无关的空镜。

## 8. 交给模型层

- 蒙太奇是多镜结构；先确认模型单次能承载几个镜头。
- 2.0 用镜头序号；2.5 用时间戳；Wan 3 用 2–5 秒分镜；通用模型问清多镜支持。
- 需要精确切点/并置节奏时，逐镜生成再剪，不把整段蒙太奇塞进一次生成。
- 声音对位（声画同步/对位）在模型提示词里单独写；不要只靠画面。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 流水账 | 只按时间排，没有关系 | 先定两条线关系/母题/对比 |
| 没有意义 | 镜头并置无呼应 | 用同一物件/颜色/声音/构图连接 |
| 乱切 | 切点没有逻辑 | 按因果/情绪/节奏切；切点落在动作/静默处 |
| 空镜凑数 | 空镜与剧情无关 | 只保留开场/情绪/转场三种功能 |
| 观众看不懂 | 时间线混乱 | 加时间锚点/字幕/声音提示；或改连续结构 |
| 情感不落 | 只有事件没有余味 | 结尾加抒情空镜/重复母题 |
| 声音平 | 只有 BGM | 写环境声、动作声、静默；声画对位 |

## 10. 示例（四镜平行）

```text
主题：同一夜，两个人为同一件事付出代价。
线 A：医院走廊，家属等待手术结果。
线 B：城市另一头，肇事者在车里发抖。
关系：平行（互不知道），靠“同一时间/同一雨夜/同一收音机新闻”连接。
镜头 1：医院走廊，时钟 23:47；家属攥着纸杯。
镜头 2：车内，雨刷；肇事者手抖，收音机播同一则新闻。
镜头 3：手术灯灭；家属站起。
镜头 4：肇事者抬头看后视镜，眼泪；切黑。
```
