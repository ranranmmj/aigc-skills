# 通用视频模型路径

> 只用于**不在** Seedance 2.0 / 2.5 / Wan 3.0 里的模型。
> 原则：**先问能力与语法，再写；不假装它是已知模型。**

## 1. 什么时候用

- 用户点名 Kling、HappyHorse、MiniMax、Sora、Runway、Luma、Pika 等。
- 用户只说“视频模型”，没有指定。
- 用户给了一条其他模型的提示词，要优化/迁移。

如果用户点名的是三个已知模型之一，回到对应方言文件，不要用本文件。

## 2. 先问能力（最多合并成 3 个问题）

| 问题 | 为什么 |
|---|---|
| 模型名/版本？ | 同名不同版本能力差很多 |
| 单次时长上限？ | 决定镜头数/拆段 |
| 参考素材类型与上限？ | 图/视频/音频/首帧/首尾帧 |
| 有原生音频吗？ | 决定声音层写法 |
| 认时间戳吗？ | 认 → 时间轴；不认 → 镜头序号/动作顺序 |
| 台词/对白怎么写？ | 引号/花括号/角色名+说；需要官方示例 |
| 有负向提示词吗？ | 有 → 独立负向；没有 → 正向约束 |
| 支持哪些特殊任务？ | 编辑/延长/首尾帧/白模/宫格/关键帧 |
| 输出画幅/格式？ | 决定参数与构图 |

用户答不上来时，让用户贴一条官方示例提示词；从示例归纳语法，不要猜。

## 3. 通用骨架

没有官方语法时，用最保守的结构：

```text
主体 + 场景 + 动作 + 运镜 + 光影 + 风格 + 声音 + 约束
```

多镜：

```text
总体描述
镜头 1（时间/动作/运镜/声音）
镜头 2（时间/动作/运镜/声音）
……
结尾：风格/声音/约束
```

要求：

- 一个镜头一个主要动作；一个镜头一个主运镜。
- 时间控制不确定时，用“先/随后/紧接着/最后”而不是精确秒数。
- 参考素材用“参考图/参考视频/参考音频”描述职责；编号按用户上传顺序。
- 台词逐字保留；不确定台词语法时，用“角色说：”+引号，并在交付时说明假设。
- 声音层至少写一句；不要 BGM 写“无背景音乐”。
- 负向支持不确定时，把“不要 X”改成正向状态描述，并在交付时说明。

## 4. 从官方示例归纳语法

如果用户给了官方示例：

1. 找**素材指代**：`@图片N` / `图N` / `Image N` / `reference image`。
2. 找**时间控制**：时间戳 / 镜头序号 / 动作顺序。
3. 找**台词**：引号 / 花括号 / 角色名+说 / 字幕。
4. 找**声音**：独立句 / 符号 / 与画面同句。
5. 找**负向**：独立字段 / 末尾清单 / 不支持。
6. 找**特殊任务**：编辑/延长/首尾帧的触发词。
7. 按示例的**段落顺序**写，不套 Seedance/Wan 3 的结构。

不确定的地方标注“按示例推断”，不要写成官方规则。

## 5. 交付时说明假设

通用路径必须带一段：

```text
【语法假设】
- 素材指代：按你给的示例用……
- 时间控制：……
- 台词/声音：……
- 负向：……
- 未确认项：……
```

这样用户能判断是否要改；不要把猜测藏进正文。

## 6. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 硬套 Seedance 语法 | 把已知模型规则当通用 | 回到官方示例；没有就保守写 |
| 时间控制错 | 不确认是否认时间戳 | 先问；不确定用动作顺序 |
| 台词被当旁白 | 台词语法不对 | 用“角色说：”+引号；问官方示例 |
| 声音空白 | 模型有音频但没写 | 显式写声音；不要就写“无背景音乐” |
| 负向无效 | 模型不支持负向 | 改正向状态描述 |
| 素材错位 | 编号与上传顺序不一致 | 按类型分别编号；交付前核对 |
| 假装官方 | 把推断写成规则 | 标注假设；让用户按平台文档复核 |
