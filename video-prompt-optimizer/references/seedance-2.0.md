# Seedance 2.0 方言

> 适用：`doubao-seedance-2-0-260128` / `doubao-seedance-2-0-fast-260128` / `doubao-seedance-2-0-mini-260615`
> 核对：2026-10-30（火山方舟公开文档 + 工作区实测）；2026-10-31 吸收官方 sd2-pe skill 增量
> **只读这一份。** 不要同时读 2.5 或 Wan 3 的参考，也不要把它们的语法带进来。

## 一句话原则

用**镜头序号**讲清“谁 · 在哪 · 做什么 · 怎么拍”，**不写精确秒数**；一个镜头只给一种运镜。

> 时长容量、拍的定义、每段该装多少信息，见 `timing-and-beats.md`（模型无关）；本文件只写 2.0 的方言语法。

## 五条红线

1. 不写 `0–3 秒`、`约第 3 秒` 这类精确时间；时序用“随后 / 紧接着 / 话音落下时 / 镜头切至”。
2. 一个镜头只指定一种运镜，不要“推拉摇移”同时上。
3. 主体每次出现都用同一标签重复绑定（`主体1@图片1`），不要写“他/她”让模型自己猜。
4. 台词用 `{}`，音效用 `<>`，音乐用 `（）`；字幕只有明确开启时才用 `【】`。
5. 素材不是越多越好：4–5 个最稳；人脸参考用“大头照 + 全身照”，不要用三视图。

## 能力边界

| 能力 | 规格 |
|---|---|
| 单次时长 | 4–15 秒（或 `duration=-1` 自动） |
| 文生 / 首帧 / 首尾帧 / 全模态参考 / 编辑 / 延长 | 均支持 |
| 参考素材 | 图片 ≤9、视频 ≤3（总长 ≤15s）、音频 ≤3（总长 ≤15s） |
| 音频单独输入 | 不支持；至少配 1 张图或 1 段视频 |
| 分辨率 | 480p / 720p / 1080p（8bit）；2.0 独有 4k（10bit H.265） |
| 宽高比 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive |
| 提示词语言 | 中、英、西班牙、印尼、葡萄牙、日 |
| 时间戳 | 不响应整数秒时间戳，只认“镜头 N”的先后顺序 |
| 多视图主体参考 | 不建议；容易换脸、出双胞胎 |
| 提示词长度 | 中文建议 ≤500 字，英文 ≤1000 词；超了模型会丢约束 |

## 三种起点互斥

同一次生成只能走其中一种：

- **首帧**：1 张图作为开场。
- **首尾帧**：2 张图，分别标为首帧、尾帧。
- **全模态参考**：参考图 0–9 张、视频最多 3 段、音频最多 3 段；视频与音频每段 2–15 秒，各自合计 ≤15 秒；音频不能单独输入。

“起始帧 + 人物图 + 地点图”只能走全模态参考，并在正文里写“@图片1 作为首帧”。
要严格对齐开场或收尾，用首帧/首尾帧模式，人物和地点只能靠那张图本身承载。

## 结构

### 按任务选句式

**全模态参考**

```text
参考图片1中的<主体特征>，生成……
参考视频1中的<动作 / 运镜 / 风格 / 音效>，生成……
参考音频1中的音色，生成……
```

**编辑**

```text
严格编辑视频1，将其中的<原特征>修改为<新特征>，<要保留的部分>保持不变。
清除视频1中<具体位置>的<元素>，保持<要保留的部分>整洁。
```

**延长**

```text
向后延长视频1，<新动作 / 新事件>，<主体与环境>保持一致。
```

**组合**

```text
参考图片1的<维度>，严格编辑视频1，<具体编辑内容>。
```

> 编辑 / 延长任务里直接写 `@视频1`，**不要写“参考@视频1”**，否则会被判成参考任务。

### 八要素一句话

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

模型内部按“空间层（画面里有什么）”和“时间层（怎么随时间变化）”拆提示词。所以写法是**工程型指令**，不是文案型形容。

### 单镜 / 多镜

- 单镜：按“起始状态 → 动作过程 → 结束状态”写，或直接按动作先后写。
- 多镜：用 `镜头1：`、`镜头2：`、`镜头3：` 分镜；每个镜头内部按“运镜/切换 → 主体动作与表情 → 位置空间 → 音频”的顺序写。
- 多镜的时序靠**镜头顺序 + 连接词**，不靠秒数。
- 一次生成多镜时，切点不保证按镜头均分；要精确切点就逐镜生成再剪。

### 复杂度分流（源自官方 sd2-pe）

按**时间维度**（事件/动作/情绪递进多不多）× **空间维度**（换不换场景/机位/区域）分流，不按素材数量分流：

- **路径 A（两轴都少）**：单一场景、单一连续动作/一段台词/一次状态展示——**一段式直组，不硬分块**：`[任务句式主体]，[主体与素材绑定]，[场景与简短动作]，[风格与约束包]`。即使台词长、动作有细，只要同一时空连续完成仍是 A。
- **路径 B（任一轴多）**：多事件链 / 空间切换 / 用户已写“镜头 1、2、3” / 长剧情——**严格三段论**：
  1. **总设定＋主体定义**：一句话定调整体场景氛围；一次性绑定全部主体与核心资产（大头照＋全身照句式、运镜参考来源一并声明）。
  2. **镜头分镜**：`镜头N：` 顺序推进，每镜按“运镜 → 主体动作与表情 → 位置空间 → 音频”四要素；禁绝对秒数；一镜一运镜。
  3. **风格＋约束包**：美术调性 + 兜底包集中挂载（见“画质、风格、约束”）。
- 编辑 / 延长 / 组合任务一律走路径 A（单点操作）。上文“按任务选句式”是语句工具集：路径 A 里作整段主语句，路径 B 里只在分镜内部作素材指代句。

## 逐元素写法

### 主体定义

```text
将图片1中穿红色连衣裙、戴草帽的女人定义为主体1
将图片1中的<特征>、图片2中的<特征>定义为主体2
```

- 核心特征用 **2–3 个稳定静态特征**（服饰、发型、外观、类别），保证唯一可识别。
- 已定义主体：每次提到都写同一标签，不要省略。
- 未定义主体：每次写 `<主体N>@<图片N>`。
- 多主体：逐个定义并起稳定标签，之后全程沿用。
- **Asset ID 屏蔽**：严禁把 `[asset-xxx]` 之类无语义 ID 裸写进动作描述，必须经 `@图片N` / `<主体N>` 桥接。
- **断句防歧义**：`@图片N` 紧接动词或方位词（“@图片1跑向…”）易触发数字粘连歧义；改为 `<主体N>@图片1`，或在 `@图片N` 后补名词隔断（“@图片1 中的女子”）。
- 人脸不准：补一张**只含头部的大头照**（无表情、少肩颈背景），写“面部特征参考图片1（大头照），妆造参考图片2（全身照）”；重要素材前置；不要用三视图。

### 动作

| 要求 | 说明 | 示例 |
|---|---|---|
| 肢体细化 + 程度量化 | 具体到手/腿/头/肩背，并补幅度、速度、力度 | 缓慢抬手、快速转头、用力蹬地、微微低头 |
| 优先低缓连续小动作 | 规避狂奔、大跳、剧烈翻滚等高爆发动作 | 缓慢行走、轻轻抬手、顺势坐下 |
| 补动作过渡 | 写清前后惯性承接 | 借着转身惯性顺势抬手、从停顿自然过渡到举手 |
| 情绪具象外化 | 用身体细节替代抽象词 | 见下表 |

**情绪外化对照**

| 抽象情绪 | 外化为动作与细节 |
|---|---|
| 悲伤 | 低头、肩膀微微颤抖、眼眶泛红、手指无意识攥紧衣角、泪在眼眶里打转但没落下 |
| 喜悦 | 嘴角抑制不住上扬、眉眼舒展、脚步轻快、忍不住原地转个圈 |
| 紧张 / 焦虑 | 频繁看手表、手指敲桌面、呼吸急促、眼神闪躲、咬指甲 |
| 愤怒 | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀、从牙缝里挤话 |
| 释然 | 长长舒一口气、肩膀完全放松、露出久违的淡淡微笑、抬头望向远方 |

### 运镜

直接用通识词：中景 / 特写 / 全景 / 缓慢推镜 / 平稳横移 / 固定镜头。
**一个镜头只给一种运镜。** 同时要求推拉摇移会显著增加画面不稳定。

### 台词、音效、音乐、字幕

| 信息 | 符号 | 示例 |
|---|---|---|
| 台词 | `{}` | `{你好，世界}`；小语种加语言：`用日语说{こんにちは}` |
| 音效 | `<>` | `<远处传来狗叫声>` |
| 音乐 | `（）` | `（背景中播放着快节奏的摇滚乐）` |
| 字幕 | `【】` | `【第一章：启程】`，仅明确开启字幕时用 |

- 台词语言统一，避免中英混用（专名除外）。
- 默认禁字幕时，正文写“全程保持无字幕，不生成对白文字叠加”，并且不出现任何 `【】`。
- 画内获准文字仍要逐字说明承载面和位置。

**文字生成三模板（源自官方 sd2-pe）**：

- 广告语：`「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」`。
- 字幕：`画面底部出现字幕，字幕内容为“…”，字幕需与音频节奏完全同步`。
- 气泡：`<角色>说：“…”，角色说话时周围出现气泡，气泡里写着台词`。

### 画质、风格、约束

| 类别 | 示例 |
|---|---|
| 画质 | 高清，细节丰富，电影质感，色彩自然，光影柔和 |
| 风格 | 赛博朋克冷蓝紫、复古胶片、日系清新、3D 国风动画 |
| 约束 | 保持无字幕 / 避免生成任何文字或字幕 / 不要生成 Logo / 不要生成水印 / 人物面部和身体比例稳定不变形 |

约束句放末尾，短而具体；不要堆二三十个名词。

**兜底包制度（源自官方 sd2-pe）**——路径 A 折叠为末尾一两句，路径 B 在第三段集中挂载：

- 默认必挂：**画质包**（高清，细节丰富，电影质感，色彩自然，光影柔和）＋**稳定包**（人物面部稳定不变形、五官清晰、动作连贯自然，不僵硬，无穿模无卡顿）＋**水印/Logo 兜底**（不要生成水印；不要生成 Logo）。
- 按场景必挂：字幕兜底（非文字生成任务）；**双胞胎兜底**（多人/多主体：禁止外形着装配饰完全一致的人物，不出现分身/双胞胎/人物重复复刻）；**风格锚定**（动漫/非写实：显式写 2D 日漫 / 3D 国漫 / 赛博朋克等）；**强方位约束**（多人正面动态：写死左右角色特征＋固定机位）。

## 素材配置

按功能角色分配：

1. **角色锚定**：锁定外观。
2. **场景定调**：锁定环境与风格。
3. **运镜参考**：锁定镜头语言与节奏。
4. **节奏氛围**：音频控制情绪、音色。

推荐 4–5 个：

```text
角色图 1–2 张（面部特写 + 全身） + 场景图 1 张 + 运镜视频 1 段 + 音频 1 段
```

不要用满 9/3/3。参考人物超过 4 人时稳定性明显下降：先分组（每组 ≤4 人）生成图片，再用这些图做图生视频。

## 编辑 / 延长

- 编辑：`严格编辑视频1，把<原特征>改成<新特征>，<保留项>不变`；点名要保留的东西比写“其他不变”更稳。
- 延长：`向后延长视频1，<新增动作>，<主体/环境/风格>保持一致`；从原片实际终点写唯一新动作。
- 轨道补齐：`视频1 + <过渡画面> + 接视频2 + <过渡画面> + 接视频3`。
- 编辑 / 延长都直接写 `@视频1`，不要写“参考”。

## 常见故障 → 修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 人物中途换脸 / 撞脸明星 | 人脸参考有效性不足、人脸占比小 | 补大头照；写“面部特征参考图片1，妆造参考图片2”；重要素材前置 |
| 出现双胞胎 | 多视图参考 + 主体定义不清 | 换单人独立照；末尾加“禁止出现外形完全一致的人物，禁止双胞胎效果” |
| 画面出现字幕 | 模型随机生成，无法 100% 避免 | 加“保持无字幕”；素材里的文字先修掉；横屏出片再裁竖屏 |
| 出现 Logo / 水印 | 参考素材带入 | 加“不要生成水印、不要生成 Logo” |
| 风格漂移 | 参考图写实 + 没强调风格 | 显式写“2D 日漫风格”“3D 国风漫画”；或先把参考图转成目标风格 |
| 延长拼接处跳变 | 帧对齐问题 | 前段末尾删 6 帧、后段开头删 1 帧；续写以切镜时刻结尾 |
| 多次延长后画质劣化 | 劣化叠加 | 先把原视频转白模再续写；控制续写次数；参考图用高清 |
| 参考人物 >4 人时多人/少人 | 稳定性下降 | 分组生图（每组 ≤4 人）再做图生视频 |
| 中文发音错（多音字/生僻字） | 读音歧义 | 换同音常用字（螭龙山 → 吃龙山） |
| 音色参考不准 | 音色特征太弱 | 补音色描述：“使用@音频1低厚温润带细碎颗粒感中年男声的音色说” |
| 特效不达预期 | 文字不足以定义特效 | 用参考视频定义特效：“数字 2999 出场方式参考视频1” |
| 首帧/首尾帧画面拉伸 | 输入图与输出分辨率宽高不一致 | 按 ratio 对应像素裁剪输入图，再用 `ratio=adaptive` |

## 优化披露与关键歧义交互（源自官方 sd2-pe）

- **四类关键歧义才打断用户**（多选确认，不静默改）：① 方位/帧位映射不明（谁左谁右/首尾帧）；② 任务类型误判风险（编辑/延长里写了“参考@视频1”）；③ 同一镜头运镜冲突（又推又拉又摇）；④ 主体特征自相矛盾。
- **非关键缺失不打断**：按八要素默认策略自动补全（缺动作默认低缓连续小动作；缺画质挂画质包；多人缺约束挂双胞胎兜底等），交付时附一段**优化问题**：已补全的缺失 + 检出的病灶（要素缺失/运镜冲突/Asset ID 裸写/任务误判/绝对秒数）+ 所用原则（Asset ID 屏蔽、断句防歧义、一镜一运镜、镜头顺序优先、双胞胎兜底、重要素材前置）。

## 交付前检查清单

- [ ] 中文是否 ≤500 字？有没有可以删掉的形容词？
- [ ] 每个主体是否只定义一次、之后全程用同一标签？
- [ ] 是否没有写 `0–3 秒`、`约第 3 秒`？
- [ ] 每个镜头是否只有一种运镜？
- [ ] 动作是否落到具体肢体 + 幅度/速度，而不是“很悲伤”“很生气”？
- [ ] 素材是否控制在 4–5 个、且每个都有明确功能角色？
- [ ] 人脸参考是否用了大头照 + 全身照（而不是三视图）？
- [ ] 末尾是否有字幕 / Logo / 水印 / 变形 的约束句？
- [ ] 台词是否用 `{}`、音效用 `<>`、BGM 用 `（）`？
- [ ] `duration` 是否在 4–15 秒之间，且与镜头数量匹配？
- [ ] 编辑 / 延长任务是否直接写 `@视频1` 而没有加“参考”？

## 禁止从 2.5 / Wan 3 带入

- 整数秒时间戳、`[0-3s]`、`第5秒` 式时间轴。
- 2.5 的“四段式”标题（素材指代 / 一句话概述 / 具体情节 / 结尾收全局）。
- Wan 3 的“七段式”结构、`图1` 指代、`说道：“…”` 台词语法、2–5 秒硬分镜骨架。
- 2.5 的 `omni_reference_task_type`、`draft`、`output_format=mov` 等参数写法。
- “只指代、不复述”的 2.5 原则：2.0 每次提到主体都要重复标签。

## 示例

**单镜，首尾帧 / 起始状态 → 动作过程 → 结束状态**

```text
将图片1中穿米色风衣、短发的女人定义为主体1，图片2作为公寓场景参考。
起始状态：主体1@图片1 背对镜头站在窗前，右手搭在窗框上，窗外是雨夜霓虹。
动作过程：镜头从背后中景缓慢推近；主体1@图片1 的手指缓慢摩挲手机边缘，肩膀轻轻塌下，
呼吸变浅；随后她微微低头，额头顶在冰凉的玻璃上。
结束状态：镜头停在后颈近景，手机屏幕的光在她侧脸上亮了一下又暗下去。
冷蓝色调，35mm 电影质感，浅景深；人物面部稳定不变形；全程无字幕、无水印；<雨声与远处车流>；（低沉的钢琴单音）。
```

**三镜，文戏**
