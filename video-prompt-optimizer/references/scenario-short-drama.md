# 竖屏短剧场景

> 模型无关。先写本集结构与视觉规范，再落到模型方言。
> 核心：**前 3 秒钩子、单镜 3–5 秒、结尾留悬念、全剧视觉统一**。

## 1. 先问清楚

| 问题 | 要拿到什么 |
|---|---|
| 题材/类型 | 玄幻、复仇、甜宠、悬疑、家庭、海外 Romance 等 |
| 本集时长 | 1.5–2 分钟（常见）；或 90/120 秒 |
| 本集钩子 | 前 3 秒观众看到什么异常/冲突 |
| 本集冲突 | 谁要什么、谁阻挡、升级到什么程度 |
| 结尾悬念 | 观众下一集想追什么 |
| 人物关系 | 主角/对手/盟友；谁和谁有张力 |
| 现有资产 | 人物三视图、场景图、道具图、参考片 |
| 目标平台 | 国内/海外；画幅、审核尺度、语言 |

> 1.5–2 分钟是**成片时长**，不是单次生成上限。按 3–5 秒镜头拆分，逐镜/分段生成后剪辑；不要指望一次生成整集。

## 2. 本集结构（1.5–2 分钟）

| 时间 | 任务 | 写法 |
|---|---|---|
| 0–3 秒 | 钩子 | 冲突/异常/强视觉动作，不要铺环境 |
| 3–15 秒 | 建立 | 谁、在哪、想要什么；用动作交代，不用旁白解释 |
| 15–45 秒 | 升级 | 阻力出现，主角第一次反击/退让 |
| 45–75 秒 | 转折 | 信息反转、身份揭露、关系变化 |
| 75–100 秒 | 高潮 | 本集最大冲突/情绪爆发 |
| 100–120 秒 | 悬念 | 新问题、新威胁、未完成的动作 |

单镜节奏：

- 常规叙事/对白：3–5 秒。
- 情绪铺垫/关键留白：4–5 秒。
- 空镜：1–3 秒。
- **单镜不超过 10 秒**。
- 开头 3 秒必须有强钩子；结尾不要总结，要留问题。

## 3. 小说/故事转剧本

原则：

- 不添加原著没有的情节；可以删支线、合并场景、调整顺序。
- 保留主线冲突、人物关系、关键台词。
- 每集要有独立的“小闭环”：本集问题 → 本集结果 → 新问题。
- 开头 3 秒钩子、结尾悬念是硬要求。
- 对白短、口语、有潜台词；不要长篇解释。

剧本格式（模型无关）：

```text
【场次】01
【地点】内/外 · 具体地点
【时间】日/夜
【人物】角色A、角色B
【动作】可见的动作与环境
【台词】角色A（情绪）："逐字台词"
【转场】硬切 / 叠化 / 甩镜
```

## 4. 全剧视觉规范（Visual Bible）

在写任何分镜前，先锁一份全剧规范：

| 项 | 要写什么 |
|---|---|
| 视觉定位 | 写实院线 / 中式水墨 / 暗黑古修真 / 亮调仙侠 / 海外 Romance |
| 画幅 | 竖屏 9:16（默认） |
| 色卡 | 主色、辅色、情绪色；给 HEX/RGB 更好 |
| 光影 | 伦勃朗侧光/平光/低调硬光；主光方向 |
| 摄影 | 机位、焦段、景深、画质、胶片颗粒 |
| 正邪区分 | 正派色温/反派色温/法术色 |
| 环境规则 | 常年雪景/山林/宗门/城市；固定天气逻辑 |
| 禁止 | 现代元素、塑料 CG、过度美颜、字幕水印等 |

固定前缀示例（按你的项目改）：

```text
竖屏 9:16，电影级写实，低饱和冷色调，ARRI 色彩科学，浅景深，
真实皮肤纹理，胶片颗粒，冷峻压抑的东方剑道玄幻氛围。
```

## 5. 资产库

写视频前确认：

- **人物**：主角/配角/反派/路人；定妆照 + 三视图/多视图 + 表情库。
- **场景**：主场景、过渡空镜、俯视结构图、九宫格/全景。
- **道具**：法器、武器、信件、饰品、关键道具多角度。
- **特效**：护体灵光、剑气、魔气、结界、传送阵；统一粒子/光晕/色彩。
- **声音**：角色固定样音、环境音、法术音效、BGM 风格。

缺资产时，先补资产提示词（见 `consistency-and-assets.md`），不要用文字硬扛“保持一致”。

## 6. 分镜脚本模板

每个镜头写：

```text
镜号：
时长：
景别：
角度：
运镜：
焦段：
光影：
画面内容：环境、天气、人物肢体、面部、微表情、道具
表演：核心动作 + 衣物/头发跟随 + 微表情
台词（情绪）：
音效：
特效：
负面控制：
参考素材：
```

要求：

- **三层动态**：核心肢体动作 + 衣物/头发跟随 + 微表情反应；不要“木头人站桩”。
- **场面调度**：一前一后、高低差、突然靠近、侧身避让、肢体拉扯；不要两个人并排说话。
- **空镜服务剧情**：开场交代、情绪留白、转场；不要无关空镜。
- **对白镜头**：正反打/过肩/反应镜头；不要一个机位念完整段。
- **动作镜头**：写清攻防因果、接触点、环境反应。

## 7. 视频生成交接

把分镜表交给模型层时：

1. 锁模型（2.0/2.5/Wan 3/通用）。
2. 读模型方言。
3. 把“时长/景别/角度/运镜/画面/表演/台词/音效/负面/参考”翻译成该模型语法。
4. 检查参考素材是否绑定到正确角色/场景/道具。
5. 音色一致：给每个说话角色固定样音；台词句与音色参考绑定。
6. 首尾帧：需要严格衔接时，用上一镜实际尾帧或生成尾帧；不要只写“保持一致”。

## 8. 海外短剧补充

常见题材：

- Romance（爱情）：Forbidden Love（禁忌恋）、Fantasy Romance（奇幻爱情）、Billionaire Romance（霸总）。
- 欧美观众更吃：关系张力、女性主动性、人物魅力、身份反转、情绪幻想。

参考片反推：

- 不要只总结剧情；按镜头拆：时间、镜头类型、画面、人物、动作、表情、情绪、环境、镜头目的。
- 恢复对白要标注“推定”；区分“画面明确出现”和“推测”。
- 原创改编至少 70% 原创；保留结构/情绪模型，不复制人物名、身份、事件、对白、场景。
- 检查“是否只是换皮”：人物行为、女性主动性、对白自然度、中国短剧痕迹。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 前 3 秒不抓人 | 开场铺环境/旁白 | 用冲突、异常、强视觉动作开场 |
| 站桩对白 | 一个机位念完整段 | 正反打/过肩/反应镜头/走位 |
| 人物漂移 | 资产不足、参考不绑 | 补三视图/多视图；逐镜绑参考 |
| 场景漂移 | 没有场景结构图 | 补俯视图/九宫格/全景；固定空间锚点 |
| 结尾平 | 本集问题解决了但没有新问题 | 加新威胁/新信息/未完成动作 |
| 单镜太长 | 把一整场塞一镜 | 拆成 3–5 秒镜头；单镜 ≤10 秒 |
| 台词被截断 | 字数超过时长 | 约 4 字/秒；拆段/加时长/删句 |
| 视觉不统一 | 没有 Visual Bible | 先锁画风/色卡/光影/相机 |
| 海外味不对 | 直接翻译国内短剧 | 按欧美题材/关系/对白重写；做本土化审核 |

## 10. 示例（本集节拍，不是最终提示词）

```text
题材：玄幻复仇
本集钩子：主角被推下悬崖，却在崖底睁开眼，手里握着仇人的剑。
0–3s   悬崖边，主角被一掌推下；镜头跟坠。
3–15s  崖底，主角睁眼，咳血；发现手里握着仇人的剑。
15–45s 回忆：仇人如何夺走一切；主角握紧剑。
45–75s 主角爬出崖底，遇到第一个阻碍（妖兽/守卫）。
75–100s 主角用仇人的剑反杀；发现剑上有宗门印记。
100–120s 远处，仇人感应到剑；主角抬头，眼神变冷。
结尾悬念：仇人知道剑在主角手里。
```
