# 竖屏短剧改编与审查 Skill

## 定位

把一个故事改编成竖屏短剧，**并且系统性查出所有逻辑漏洞**。不限题材。

**主打能力：逻辑审查。** 改编容易，审查难。这个 skill 的核心价值是把"查漏洞"从"觉得哪里怪怪的"变成一套可重复的 8 维度检查方法。

解决的问题：

- 这个故事值不值得改短剧，改什么、砍什么
- 原著怎么重构成短剧节奏（不是"把小说拍出来"）
- 视觉设计怎么有理有据（不是"觉得好看就拍"）
- 两集 90–120 秒怎么装下一个完整弧线
- 结尾怎么留白（浮想联翩，不是讲完）
- **逻辑漏洞怎么系统性地查出来（核心）**

## 默认输入

`一段对目标故事的描述 / 一个原著文本 / 一个剧情点子 / 一个已有剧本 / 一个分镜脚本`

默认行为：

1. 先判断任务属于哪个阶段（选材→建故事→重构→写剧本→出分镜→**审查**）。
2. 信息够用就直接做当前最需要的那一层；不够就只补最少量澄清。
3. **每层做完必须过逻辑审查**，不能直接交稿。

## 输出原则

- 默认只输出当前最需要的一层，不把所有东西一次堆满。
- 用**视觉描述级**（散文体描述画面），不用表格流水账。
- 每个视觉选择必须回答"**为故事服务什么**"。答不上来，删掉。
- 结尾留白 > 讲完。观众的问题比答案更有力。
- **审查报告必须给出具体修法**，不只说"有问题"。

## 总流程

```
1. 选材评估  →  2. 故事构建  →  3. 结构重构  →  4. 逻辑审查 ← 主打
                                                        ↓
6. 成片交付  ←  5. 分镜设计  ←  剧本定稿  ←  4b. 视觉设计
```

## 模块职责

### 4. 逻辑审查（主打模块）

**做什么**：系统性地查逻辑漏洞。每场/每个镜头都要过。

**8 维度检查表**（按严重程度排）：

| 维度 | 问题 | 例子 | 严重度 |
|---|---|---|---|
| **情节硬伤** | 故事不成立 | 钥匙放在进不去的地方 | ★★★★★ |
| **自相矛盾** | 同一段文字自己打架 | "画面全黑"又说"画面开始变暗" | ★★★★★ |
| **空间矛盾** | 位置/机位不一致 | "切全景"拍到不该出现的人 | ★★★★ |
| **时间矛盾** | 年龄/时序对不上 | 11 岁→18 岁 = 7 年，不是 3 年 | ★★★★ |
| **媒介矛盾** | 文字说法不适用于视觉 | "我上面写的"→ 应该是"我刚才说的" | ★★★ |
| **规则违反** | 自己定的规则没遵守 | 说"只露一次脸"但后来又露了 | ★★★ |
| **信息缺失** | 观众会追问的没写 | 动机是什么？道具从哪来？ | ★★★ |
| **角色行为** | 人物做了一件不符合人设的事 | 一个谨慎的人犯了低级错误 | ★★ |

**审查方法**：

1. 每轮审查**只查一个维度**，不混着查。
2. 查完**立刻改**，不攒着。
3. 改完**再过一遍**，确认没有连带问题。
4. 至少做**两轮**：第一轮查硬伤（★★★★★），第二轮查细节（★★★以下）。

**审查输出格式**：

```
| # | 问题 | 位置 | 修法 |
|---|---|---|---|
| 1 | 钥匙放在进不去的地方 | 场景 3 L223 | 改成"进去以后放在工作台上" |
| 2 | "画面全黑"又说"画面开始变暗" | 场景 4 L118-128 | 开场改成"很暗"，不是"全黑" |
```

**输出**：问题清单 + 修法（每条都有具体改法）。

### 1. 选材评估

**做什么**：判断一个故事值不值得改编成短剧，以及怎么改。

**检查清单**：

| 项 | 问题 | 不合格的信号 |
|---|---|---|
| **核心冲突** | 有没有一个让观众想看下去的"钩子"？ | 开头平淡，没有悬念/欲望/困境 |
| **角色** | 有没有一个让观众记住的人？ | 所有人都是工具人 |
| **可拍性** | 竖屏 + 实景能不能拍？ | 需要特效/大场面/多人调度 |
| **节奏** | 故事的"慢"能不能变成短剧的"快"？ | 依赖大段心理描写/风景描写 |
| **结尾** | 有没有留白空间？ | 所有事都交代完了 |

**输出**：一段话结论 + 改编方向。

### 2. 故事构建

**做什么**：从原著/点子建一个完整的故事。不限题材。

**核心原则**（按题材选用）：

| 题材 | 核心技巧 | 例子 |
|---|---|---|
| **悬疑/推理** | 叙述者不可靠；凶器 = 死者的日常物件 | 开场认罪→翻供→真相 |
| **爱情/关系** | 用物件承载情感；对白不说破 | 一把伞、一条围巾、一个未接来电 |
| **家庭/伦理** | 用日常动作暗示权力关系 | 做饭、叠衣服、挑鱼刺 |
| **恐怖/惊悚** | 少给画面，多给声音 | 只拍脚、只拍手、只拍门缝 |
| **科幻/奇幻** | 用一个具体设定制造困境 | 一条规则、一个能力、一个选择 |

**通用技巧**：

- **视觉母题贯穿全片**：一个物件/动作/颜色，在每个关键节点出现，意义递进。
- **双读镜头**：第一次看是日常，回头看是恐怖/心酸/讽刺。
- **声音承载叙事**：画面越少，观众越接近角色的感知方式。

**输出**：短篇故事（3000–5000 字）或故事大纲。

### 3. 结构重构

**做什么**：把长故事压缩成两集短剧，每集 90–120 秒。

**结构原则**：

- **每集一个完整弧线**（钩子→推进→高潮→结尾），不是"把 N 节切两半"。
- **第一集结尾 = 悬念**（观众知道要发生什么，但不知道会怎样）。
- **第二集结尾 = 留白**（不给答案，让观众自己填）。

**处理方式**：

| 原著内容 | 处理 | 原因 |
|---|---|---|
| 核心冲突/钩子 | 保留 | 这是卖点 |
| 背景/动机 | 压缩成 1-2 句 | 时间不够 |
| 次要角色 | 砍掉或变成声音 | 竖屏装不下群戏 |
| 心理描写 | 变成画面（表情、手、物件） | 短剧是视觉媒介 |
| 解释性对白 | 删掉 | 留白 > 交代 |
| 环境描写 | 变成 1-2 个空镜头 | 建立氛围，不拖节奏 |

**留白清单**（不解释，让观众想）：

| 留什么 | 观众会想 |
|---|---|
| 没有答案的问题 | 他/她最后怎么了？ |
| 听不清的对白 | 他说了什么？ |
| 空着的位置/未完成的动作 | 下一个是谁？/ 她做了吗？ |
| 不解释的动机 | 为什么这样做？ |
| 永远不出现的人 | 那个人是谁？ |

**输出**：两集剧本（干净版，只要场景+画面+对白）。

### 5. 视觉设计

**做什么**：设计画面、光线、构图、声音。每个选择都要有依据。

**视觉设计总则**（不限题材，按需选用）：

| 规则 | 含义 | 适用题材 |
|---|---|---|
| **极端特写是默认景别** | 观众被迫看细节 | 恐怖/悬疑/心理 |
| **物件即角色** | 道具和人一样重要 | 全部 |
| **声音是叙事者** | 很多场景靠声音推 | 恐怖/悬疑/回忆 |
| **光线 = 状态** | 暖光=日常/表演，冷光=真相/隐藏 | 悬疑/家庭 |
| **构图 = 关系** | 竖向三段=囚笼，对称=控制，倾斜=不安 | 全部 |
| **留白 > 交代** | 不解释、不说破 | 全部 |

**"为什么"原则**：每个镜头必须写"为什么拍这个"。

**输出**：视觉设计总则 + 示意图（按需）。

### 6. 分镜设计

**做什么**：把剧本拆成逐颗镜头。

**格式**（视觉描述级）：

```
### 场景 X · 标题（约 X 秒）

**镜头 1**（ECU / CU / MS · X 秒）
[散文体画面描述]

**声音**：[声音设计]

**参考**：[参考作品 + 具体技法]
**为什么拍 XX**：[为故事服务什么]
```

**参考作品**（按题材）：

| 题材 | 参考 | 借什么 |
|---|---|---|
| 恐怖/惊悚 | 《遗传厄运》《隐形人》 | 手/物件特写、声音恐怖 |
| 悬疑/推理 | 《利刃出鞘》《消失的爱人》 | 叙事诡计、视觉线索 |
| 家庭/伦理 | 《寄生虫》《佛罗里达乐园》 | 日常动作=隐喻 |
| 爱情/关系 | 《爱在三部曲》《蓝色情人节》 | 对白不说破、物件承载情感 |
| 科幻/奇幻 | 《降临》《黑镜》 | 具体设定、一个选择的重量 |
| 战争/动作 | 《1917》《拯救大兵瑞恩》 | 跟拍、声音标记时间 |

**输出**：分镜脚本 + 特写索引 + 结构节拍表。

### 7. 成片交付

**交付清单**：

- [ ] 故事/短篇小说
- [ ] 两集剧本（干净版）
- [ ] 分镜脚本
- [ ] 视觉设计总则 + 示意图
- [ ] **逻辑审查报告**（最重要）

## 留白原则

> **观众的问题比答案更有力。**

| 讲完 | 留白 |
|---|---|
| 观众想"哦，原来是这样" | 观众想"等等，那……" |
| 看完就放下 | 看完还在想 |
| 记住一个答案 | 记住一个问题 |

---

## 去 AI 味

- 能用动作，不用总结
- 能用对白，不用解释
- 能写具体，不写抽象
- 每个人说话带身份感
- 不要"美丽的道理"——"我打算拦住她"比"她感到深深的无力"好一百倍

---

## 边界

**不要做的事**：
- 不要为了"好看"拍一个和故事无关的镜头
- 不要把解释性对白塞进结尾
- 不要在一轮审查里混查多个维度
- 不要平铺所有场景
- 不要用电影参考替代短剧节奏检查

**默认鼓励的事**：
- 每个镜头写"为什么"
- 每轮审查只查一个维度
- 留白 > 交代
- 声音承载叙事
- 双读镜头
- 用物件/动作代替心理描写
