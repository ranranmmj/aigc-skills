# TVC / 广告场景

> 模型无关。先写策略与结构，再交给模型方言。
> 核心公式：**TVC = 商业策略 × 创意概念 × 视觉语言 × 情绪价值**。

## 1. 先问清楚五件事

| 问题 | 要拿到什么 |
|---|---|
| 卖什么？ | 产品/服务/品牌 |
| 给谁？ | 目标人群、城市、消费层级 |
| 核心卖点？ | 一句话能说清的利益点 |
| 为什么信？ | 证据：材质、实验、场景、用户证言、权威 |
| 希望什么行动？ | 记住品牌、搜索、购买、到店、转发 |

缺任何一项，先问；不要直接写画面。

## 2. 策略一句话

模板：

> 这不是一个关于**\_\_\_\_**的广告，而是一个关于**\_\_\_\_**的故事。

例子：

- 不是“展示新能源汽车性能”，而是“讲述一家人因为一辆车重新发现世界”。
- 不是“展示护肤品成分”，而是“讲述一个人决定不再遮住自己的脸”。

这句话决定全片方向；写不出就先别写分镜。

## 3. 三个创意方向

每个方向写：

```text
方向名称：
一句话概念：
核心主题：
人物/主体：
冲突/欲望：
视觉记忆点：
情绪价值：
风险：
```

三种常用方法：

1. **视觉隐喻**：产品特征 → 一个可拍的视觉符号。
   - 紫色车身 → 晚霞、家庭幸福、未来幻想。
2. **世界观创造**：把产品放进一个超现实/类型化世界。
   - 普通：孩子坐车旅行；高级：孩子进入由汽车开启的幻想宇宙。
3. **情绪放大**：卖的不是产品，是梦想、身份、情感、价值观。

三个方向要**真正不同**，不要只换场景。

## 4. 高级感三要素

### 光

- 低级：均匀亮。
- 高级：光制造情绪。
- 例子：夕阳光 = 家庭温暖；冷蓝光 = 科技未来；单侧硬光 = 决断/危险。

### 构图

| 构图 | 作用 |
|---|---|
| 大空间 | 品牌高度、世界观 |
| 极近特写 | 产品价值、材质、细节 |
| 人与产品关系 | 情绪连接、使用场景 |

### 镜头

| 焦段 | 作用 |
|---|---|
| 24–35mm | 空间感、环境关系、史诗感 |
| 50mm | 真实关系、自然视角 |
| 85mm | 高级人物肖像、产品特写、浅景深 |

不要一部片全用同一焦段；用焦段变化制造层次。

## 5. 视觉记忆点

公式：

```text
产品特点 → 视觉符号 → 消费者记忆
```

例子：

- 苹果：极简白、留白、产品悬浮。
- 奔驰：速度与力量、低机位、动态。
- 劳斯莱斯：尊贵仪式、对称、深色。

写广告提示词时，**全片只保留一个最强记忆点**；不要每 5 秒换一个符号。

## 6. 产品登场时机

不要开头就摆产品（除非产品本身就是奇观）。高级结构：

```text
先建立世界 → 制造期待 → 产品成为答案
```

60 秒经典结构：

| 时间 | 任务 |
|---|---|
| 0–5 秒 | 吸引注意：强视觉/异常/冲突 |
| 5–20 秒 | 建立情绪：人物、关系、世界 |
| 20–40 秒 | 产品出现：成为解决问题的答案 |
| 40–60 秒 | 品牌升华：口号、品牌画面、落点 |

30 秒压缩：

| 时间 | 任务 |
|---|---|
| 0–3 秒 | 钩子 |
| 3–12 秒 | 情绪/问题 |
| 12–22 秒 | 产品/答案 |
| 22–30 秒 | 品牌落点 |

15 秒压缩：

| 时间 | 任务 |
|---|---|
| 0–2 秒 | 钩子 |
| 2–8 秒 | 产品/使用 |
| 8–12 秒 | 利益点/证据 |
| 12–15 秒 | 品牌落点 |

> 60 秒是**成片时长**，不是单次生成上限。按镜头拆分，逐镜/分段生成后剪辑；不要把整条 60 秒塞进一次生成。

## 7. 60 秒分镜骨架

| # | 时间 | 内容 | 目的 |
|---|---|---|---|
| 1 | 0–5s | 强视觉开场：一个不寻常的画面/声音/问题 | 抓住注意力 |
| 2 | 5–12s | 人物与世界：谁、在哪、想要什么 | 建立情绪 |
| 3 | 12–20s | 阻力/问题：没有产品时的困境 | 制造需求 |
| 4 | 20–28s | 产品介入：第一次出现，改变局面 | 产品成为答案 |
| 5 | 28–40s | 使用/证据：材质、细节、场景、效果 | 建立信任 |
| 6 | 40–50s | 情绪高点：人与产品的关系 | 情绪价值 |
| 7 | 50–60s | 品牌落点：口号/品牌画面/行动 | 记住品牌 |

每个镜头写：景别、角度、运镜、画面、动作、台词/旁白、音效、产品是否在画面。

## 8. 资产清单

写视频提示词前，确认这些资产：

- 产品多角度高清图（正面/侧面/细节/材质）。
- 品牌 Logo/标准字/包装。
- 人物定妆照/三视图（如果有演员）。
- 场景原图/场景板。
- 参考片（如果有）。
- 品牌色卡/字体规范。

缺资产时，先补资产提示词（见 `consistency-and-assets.md`），不要用文字硬扛“产品保持一致”。

## 9. 交给模型层

把第 7 节的分镜表翻译成目标模型语法：

- 先确认模型（2.0/2.5/Wan 3/通用）。
- 再读对应方言。
- 广告片常见的“产品特写/材质细节/品牌落点”要写进模型提示词，不要只留在分镜表里。
- 产品文字/Logo 不要让模型生成；用后期叠加或参考图承载。

## 10. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 像普通 AI 视频，不像广告 | 没有策略/卖点/品牌 | 先写策略一句话与视觉记忆点 |
| 产品不清楚 | 产品图不足、镜头太远 | 补产品多角度图；加极近特写 |
| 廉价感 | 均匀光、塑料材质、特效堆砌 | 光制造情绪；材质特写；减少特效 |
| 点子太多 | 每条都想说 | 全片只留一个记忆点 |
| 品牌缺席 | 结尾没有落点 | 最后 3–5 秒给品牌画面/口号 |
| 产品登场太早 | 没有建立期待 | 按 0–5/5–20/20–40/40–60 结构 |
| 文字乱码 | 让模型生成 Logo/口号 | 后期叠加；或用参考图承载 |

## 11. 示例（结构，不是最终提示词）

需求：60 秒新能源汽车 TVC，卖“家庭生活方式”。

```text
策略：不是展示性能，而是讲述一家人因为一辆车重新发现世界。
记忆点：车顶天窗 = 孩子第一次看见整片星空。
结构：
0–5s   城市夜景，孩子趴在窗边看灯，父亲在收拾行李。
5–20s  一家人上车，车内安静，孩子问“我们真的能看到星星吗？”
20–40s 车驶出城市，天窗打开，星空出现；孩子伸手。
40–50s 父母对视，笑；车停在湖边，一家人下车。
50–60s 品牌画面 + 口号 + 产品定格。
资产：车多角度图、内饰图、家庭人物三视图、夜景/湖边场景图。
```
