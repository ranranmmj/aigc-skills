# 导演工作流（多镜项目）

> 模型无关。用于 40–120 秒短片、整集短剧、多镜广告。
> 定位：写提示词前的“结构与资产检查”，不是项目管理系统。

## 1. 什么时候用

- 一条片子超过 3 个镜头。
- 需要跨镜一致性（人物/场景/道具/光线）。
- 需要先定视觉规范，再逐镜写提示词。
- 需要给客户/导演看分镜表，而不是直接跑模型。

单镜、简单需求不需要走完整流程；直接用场景配方 + 模型方言。

## 2. 七阶段（压缩版）

| 阶段 | 任务 | 产出 |
|---|---|---|
| 1 立项 | 用途、时长、主题、受众、核心价值 | 一句话 brief |
| 2 创意 | 3 个方向、故事结构、剧本 | 创意方案 + 剧本 |
| 3 视觉 | 视觉定调、色卡、光影、画风 | Visual Bible |
| 4 资产 | 人物/场景/道具/特效 | 资产库 |
| 5 分镜 | 镜头表、故事板 | 分镜脚本 |
| 6 生成 | 逐镜提示词、生成、初筛 | 镜头素材 |
| 7 后期 | 剪辑、音频、调色、字幕、交付 | 成片 |

口诀：**立方案 → 搭资产 → 画分镜 → 生视频 → 做音频 → 剪片子 → 交成片。**

## 3. Visual Bible

任何多镜项目先锁一份全片规范：

| 项 | 要写什么 |
|---|---|
| 视觉定位 | 写实/动画/国风/赛博/甜宠/暗黑；一句话 |
| 时代/地域 | 古代/现代/未来；城市/山林/宗门 |
| 美术风格 | 参考作品 + 关键词 + 禁止项 |
| 色彩 | 主色/辅色/情绪色；HEX/RGB 更好 |
| 光影 | 主光方向、色温、对比、风格（伦勃朗/平光/硬光） |
| 摄影 | 机位、焦段、景深、画幅、画质、颗粒 |
| 材质 | 皮肤/布料/金属/石材/特效的统一质感 |
| 情绪 | 全片情绪曲线与关键词 |
| 画幅 | 16:9 / 9:16 / 2.39:1 |
| 禁止 | 现代元素、塑料 CG、过度美颜、字幕水印等 |

固定前缀示例：

```text
竖屏 9:16，电影级写实，低饱和冷灰色调，ARRI 色彩科学，
浅景深，真实皮肤纹理与胶片颗粒，冷峻压抑的东方剑道玄幻氛围。
```

## 4. 镜头表字段

每个镜头至少写：

```text
镜号：
场次：
时间（起-止）：
时长：
景别：
角度：
运镜：
焦段：
光影：
镜头目的：建立/制造冲突/展示关系/揭露秘密/制造悬念
画面内容：
人物动作：
表演/微表情：
台词（情绪）：
音效：
特效：
负面控制：
参考素材：
```

要求：

- **镜头目的**必须写；没有目的的镜头删掉。
- 每个镜头只承担一个主要功能。
- 多镜之间写清“上一镜结束状态 = 下一镜开始状态”。
- 转场写清方式（硬切/叠化/甩镜/匹配剪辑）。

## 5. 节奏模型

### 40 秒

```text
0–5s   视觉钩子
5–25s  事件展开
25–35s 情绪高潮
35–40s 主题落点
```

### 60 秒

```text
开场 → 人物 → 冲突 → 转折 → 高潮 → 结尾
```

### 90–120 秒

微电影结构：

```text
建立人物/世界 → 事件升级 → 转折 → 高潮 → 余味
```

### 30 秒动作

10 镜 × 3 秒；每秒一个动作节拍（见 `scenario-action.md`）。

## 6. 评审与评分

满分 100：

| 项 | 分值 | 看什么 |
|---|---|---|
| 故事性 | 25 | 主题、冲突、变化 |
| 情绪价值 | 25 | 共鸣、记忆点 |
| 视觉创造力 | 20 | 视觉符号、世界观 |
| 镜头语言 | 15 | 电影感、节奏 |
| AI 执行 | 15 | 一致性、可实现性 |

多角色审稿：

- **编剧**：故事成立吗？冲突够吗？
- **导演**：镜头高级吗？有电影感吗？
- **美术**：世界独特吗？视觉统一吗？
- **观众**：前 10 秒抓人吗？结尾有记忆吗？

低于 70 分先改结构，不要靠堆特效。

## 7. 交给提示词层

1. 先定 Visual Bible 与镜头表。
2. 按场景配方（TVC/短剧/动作/情绪/蒙太奇）写段落结构。
3. 按 `visual-language.md` 写景别/角度/运镜/色彩。
4. 按 `consistency-and-assets.md` 检查资产与跨镜锚点。
5. 最后读模型方言，逐镜翻译成模型语法。
6. 多镜项目不要把所有镜头塞进一条提示词；逐镜/分段生成，后期剪。

## 8. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 全片风格不统一 | 没有 Visual Bible | 先锁画风/色卡/光影/相机 |
| 镜头没有目的 | 为好看而拍 | 每个镜头写目的；删无功能镜头 |
| 跨镜跳变 | 上一镜结束 ≠ 下一镜开始 | 写结束状态；复用空间锚点 |
| 节奏拖 | 镜头太长/信息重复 | 3–5 秒/镜；删重复；加钩子 |
| 情绪不落 | 只有事件 | 加反应镜头/空镜/母题 |
| 资产不够 | 边写边找图 | 先建资产库再写分镜 |
| 生成不可控 | 镜头太大/太复杂 | 拆镜；一镜一动作；先小样 |
