# 动作 / 打戏场景

> 模型无关。先写动作结构与角色区分，再落到模型方言。
> 核心：**30 秒 10 镜 × 3 秒，每秒一个动作节拍；角色必须一眼分清；特效必须绑定动作**。

## 1. 先问清楚

| 问题 | 要拿到什么 |
|---|---|
| 双方是谁 | 人数、身份、体型、服饰、武器 |
| 视觉区分 | 颜色、武器、身法、能量色；至少两项强对比 |
| 战斗空间 | 地点、地形、可破坏物、限制（窄巷/空中/水面） |
| 开场状态 | 从第 0 秒就处于什么动作（对冲/追击/对峙） |
| 结束状态 | 谁占上风、环境变成什么样、是否留续 |
| 时长/画幅 | 30 秒（10×3）、15 秒（5×3）或其他 |
| 特效边界 | 允许什么、不允许什么；高级感关键词 |

## 2. 30 秒结构（10 镜 × 3 秒）

| 镜头 | 时间 | 阶段 | 作用 |
|---|---|---|---|
| 1 | 0–3s | 开场碰撞 | 首次正面对撞，确立强度 |
| 2 | 3–6s | 追击回合 | A 压 B，B 反打 |
| 3 | 6–9s | 升空/换位 | 转战空中/新空间，密度提升 |
| 4 | 9–12s | 贴身肉搏 | 最密集的一轮攻防 |
| 5 | 12–15s | 对拼升级 | 三次交锋，特效升级 |
| 6 | 15–18s | 交错 | 轨迹交叉，空间翻转 |
| 7 | 18–21s | 回落实战 | 落地后继续 |
| 8 | 21–24s | 环境最狂暴 | 风暴/崩塌/爆炸 |
| 9 | 24–27s | 坠落/极限 | 自由落体/失衡继续打 |
| 10 | 27–30s | 终极对拼 | 最大冲击波，留续 |

15 秒版：取 1、2、4、8、10 的压缩版，每镜 3 秒。
每镜内部按“t=Xs / t=X+1s / t=X+2s”写三个动作拍；**一镜一拍一个主动作**，不要每秒塞三个动作。

## 3. 角色锁定

两个角色必须有**区分明确的视觉标识**，否则模型会串角色：

```text
角色A
外形：性别、年龄、服饰、发型、体型
动作风格：直线猛冲 / 压迫式连斩 / 爆发型冲刺
武器：类型 + 不可变成其他武器
能量视觉：颜色 + 形态（如赤白高压风火剑流）
视觉表现：高速红白刀风、热流切痕、气流爆鸣

角色B
外形：与 A 形成强对比
动作风格：弧线突进 / 空中折返 / 飘逸游斗
武器：类型 + 不可变
能量视觉：与 A 强对比（青白/冷蓝/紫）
视觉表现：青白风旋、冷雾切流、真空刃痕
```

设计要点：

- 能量颜色强对比（赤白 vs 青白、红 vs 蓝）。
- 身法相反（直线 vs 弧线、压迫 vs 游斗）。
- 服饰差异大（便于模型区分）。
- 武器固定，不允许中途变形/换武器。

## 4. 场景与环境

- 场景严格继承首帧/场景资产；不要每个镜头换一个地方。
- 写清主要地形、前景/中景/远景、可破坏物。
- 战斗中环境必须**持续被破坏**：
  - 断桥崩裂、石块被斩碎、云层被切开、冲击波形成真空裂痕、大块岩石被掀飞。
- 环境服务于动作推进，不是静态背景；但不要每个镜头都大爆炸，破坏要有节奏。

## 5. 特效规则

特效必须**高级、锋利、绑定动作**，不能廉价：

| 动作 | 允许的特效 |
|---|---|
| 高速突进 | 尾流、拉丝气痕、局部过曝、轻微抽帧 |
| 兵器碰撞 | 火星、真空震纹、短促音爆、透明冲击环 |
| 极快斩击 | 弧形空气切痕、短马赫环、风压裂口 |
| 高强度对拼 | 黑白闪击 1–2 帧、瞬时全画面过曝、空气扭曲 |
| 超高速身法 | 极短暂运动切片感，不是“分身” |
| 重击环境 | 碎石爆散、结构断裂、介质被切开、物体翻滚 |

禁止：廉价彩虹特效、游戏 UI、乱飞法阵、悬空能量球、塑料光柱、纯特效堆砌。

## 6. 负面词库（可直接用）

```text
不要廉价特效，不要游戏UI，不要发光法阵，不要悬空能量球，不要塑料光柱，
不要随意分身，不要第三人，不要人物复制，不要武器变形，不要突然换脸，不要换装，
不要动作停顿，不要站桩对波，不要长时间悬空摆pose，不要慢动作，
不要莫名其妙的镜头乱晃，不要低级爆炸贴图，不要看不清动作的纯拖影，
不要失去空间逻辑，不要环境忽然重置恢复。
```

按目标模型的支持范围使用；有些模型只对字幕/音频负向有明确支持，画面问题优先正向锁定。

## 7. 单镜模板

```text
镜头N（X–Ys）
t=Xs：运镜 + 景别 + 谁从哪里冲、做什么攻击、对方如何应对；碰撞/特效。
t=X+1s：运镜变化 + 下一拍动作；碰撞/特效。
t=X+2s：收尾动作（击退/追击/转场）；环境破坏。
```

要求：

- 每拍一个主动作；攻防因果可追踪。
- 写清接触点（剑刃/拳头/脚/地面）与方向。
- 镜头运动不要每拍都换；一镜一主运镜。
- 动作速度极快，但不是快进；要能看清兵器轨迹、身法位移、攻防因果。

## 8. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 角色串了 | 视觉标识不够 | 强化颜色/服饰/武器对比 |
| 变慢动作 | 没强调节奏 | 加“不是快进但速度极快”“平均每秒都有动作变化” |
| 特效廉价 | 没限制特效 | 照抄第 5/6 节；绑定动作 |
| 动作看不清 | 过度拖影 | 加“能看清兵器轨迹、身法位移、攻防因果” |
| 站桩对波 | 没强调近战 | 强调“空中高速近战/贴身短打” |
| 环境静止 | 没写破坏 | 逐镜写环境破坏 |
| 提前结束 | 没写运动收尾 | 加“不是定格，运动中结束” |
| 空间乱 | 没写站位/方向 | 写左/右/前/后、距离、朝向 |
| 人物变形 | 物理交互弱项 | 拆段、换局部视角、写清肢体数量与接触后形态 |

## 9. 交给模型层

- 30 秒 10 镜：确认模型单次上限；2.0 需要拆段，2.5/Wan 3 可尝试多镜但注意切点。
- 每镜/每段写清动作节拍与时长；不要把所有镜头塞进一条提示词。
- 特效与负面词按模型支持范围改写；不要直接把本文件的词库当模型语法。

## 10. 示例（结构）

```text
题材：仙侠空战
角色A：赤白风火剑流，直线猛冲，深棕灰长袍
角色B：青白云涡剑流，弧线游斗，灰白层叠长袍
场景：云海之上的崩裂遗迹；断桥、悬浮石、远处风暴气旋
30 秒 10 镜：开场对冲 → 追击 → 升空 → 贴身 → 对拼升级 → 交错 → 回落 → 风暴中心 → 坠落交战 → 终极对拼
环境破坏：断桥崩裂、石块斩碎、云层切开、冲击波真空裂痕
```
