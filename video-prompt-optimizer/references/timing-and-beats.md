# 时长与拍法（模型无关）

> 只回答两件事：**一个镜头该多长、一段能装多少信息**。
> 不写任何模型的具体语法；时间戳写法、硬分镜骨架、参数联动见对应方言文件。
> 数据来源：9 部短片 551 个镜头的统计（山音导演 skill）、Seedance 2.5 节拍实操总结、电影剪辑经验。区间是**经验参考值**，不是官方标准。

## 1. 拍的定义

- **一拍 = 观众能读懂的一次可辨识动作或信息变化。**
- 时长随段落类型变：快切段 2–3 秒 / 建立与情绪段 4–5 秒 / 转折段 5–7 秒（与 §3.1 一致）；快节奏类型（追车、打斗、短剧）整体可下压 1 秒左右；低于 2 秒，观众只感知到有东西在动，读不懂发生了什么。
- 一条物理连续动作链的子相（抓杆→拖胸→勾膝→拉回）算**一拍**；观众不需要逐步读中间态。
- 判断方法：问“这个动作要让观众读懂几次”——一次 = 一拍。
- 非连续的多动词，模型通常只挑一个执行；连续链写多个动词没问题。

## 2. 三类拍（内容分类，不提供乘数）

| 类别 | 判据 | 时间关系 |
|---|---|---|
| 质感拍 | 不改变状态，只提供真实感：呼吸、颤抖、雨水、水花、肌肉绷紧、衣料湿重 | 不占独立时长，附着在叙事拍上；纯质感镜（空镜/环境）2–3 秒起 |
| 叙事拍 | 一次状态变化或一条新信息：发现、喊出、抓住、撕裂、拿起 | 2–3 秒 |
| 顺序拍·链条式 | 多个动作构成一个物理连续体：坠落、拉回桥面、连续发力 | 整条 3–8 秒，**不按步数计** |
| 顺序拍·断点式 | 多个动作之间有发现、转折、决策：跑入→僵住→喊→扑岸 | 拆成“动作-反应”单元，每单元 2–3 秒 |

> 三类拍决定“怎么算时间”，**不要乘系数**。动作本身的物理时长差异很大：抬手 0.5 秒、转身 1 秒、连续拉拽 3 秒以上。

## 3. 四张区间表

### 3.1 按叙事功能

| 功能 | 区间 |
|---|---|
| 推进 / 升级 | 2.5–3.5s |
| 交代 / 建立 | 4–5s |
| 展现 / 呈现 | 4–5s |
| 情绪 / 氛围 | 4–5s |
| 呼应 / 闭环 | 4–5s |
| 转折 / 翻转 | 5–7s |
| 升华 / 主旨 | 6–10s |

### 3.2 按信息层数（最常用判据）

读取一层 ≈ 2–3 秒，每多一层加 2–3 秒：

| 信息层数 | 区间 | 典型 |
|---|---|---|
| 单一信息 | 2–3s | 一个物件特写、一个简单动作 |
| 双重信息 | 4–5s | 一个动作 + 环境关系、一句台词 + 反应 |
| 多层信息 | 6–8s | 复杂场面、多人互动、误导 + 揭示 |
| 综合段落 | 10–15s | 长镜调度、景别转换镜头、情绪留白 |

### 3.3 按景别

| 景别 | 区间 |
|---|---|
| 特写 | 2–4s |
| 中景 | 3–5s |
| 全景 | 4–5s |
| 远景 | 5–7s |
| 景别转换镜头（推/拉/摇移中变景别） | 8–12s |

### 3.4 按镜头组

| 镜头组 | 组内镜数 | 组总长 | 每镜 |
|---|---|---|---|
| 快切蒙太奇组 | 3–14 镜 | 6–20s | 1–2s |
| 递进介绍组 | 3–5 镜 | 6–12s | 2–3s |
| 标准叙事组 | 2–4 镜 | 8–16s | 3–5s |
| 情绪留白组 | 1–3 镜 | 8–20s | 5–15s |

### 3.5 四张表怎么合并

以**信息层数**为主判据；功能表与景别表做**上限校正**（转折、远景给更长）；镜头组表做**下限校正**（快切组可以更短）。三者冲突时以信息层数为准。台词不单独占层，规则见 §4。

### 3.6 上限与格式

- 单镜 / 单组尽量 **≤15 秒**；超过必须有内部视觉变化（主体运动、焦点转换、光线变化）或明确的节奏意图。
- 短片（3–7 分钟）平均 3–5 秒/镜；长片 5–8 秒；剧集 4–6 秒。
- 快节奏不是每镜都快：快镜和慢镜的对比，才让快的更快、慢的更慢。

## 4. 台词：脑内演一遍

- 不要用“字数 ÷ 固定语速”。语速随角色性格、年龄、情绪状态、场景节奏变化。
- 同一句 10 字台词：急躁青年在争吵中可能 1.5 秒；沉稳老人在回忆中可能 5 秒（有停顿、呼吸、沉默）；醉酒含混可能 4 秒。
- 方法：用这个角色在这个情境下的语速、停顿、呼吸把台词“演”一遍——读完的时间就是台词时间；再单独加反应时间（听者的停顿、表情变化）。
- 实测经验：喊叫、哭喊类台词远快于书面估算；字数公式只能当粗筛，不能当判据。

### 4.1 台词×拍×时长

| 台词时长（演一遍后） | 处理 |
|---|---|
| ≤2 秒（短促喊话，约 8 字内） | 骑在动作拍上，**不单独增层**；该拍仍按 2.5–3.5 秒 |
| 2–4 秒（一句完整台词） | 该拍升为“动作 + 台词”双层（4–5 秒），或拆成台词拍 + 反应拍 |
| >4 秒 | 拆句、加时长或删句；不要一镜硬塞 |

- 台词不凭空增加拍数：短促喊话附着在动作拍上；完整台词才升层或另起一拍。
- 例：8 秒装 3 个动作拍 + 1 句短喊话 → 2 + 3 + 3 = 8 秒（台词骑在中间拍）。若台词超过 2 秒，减一拍或加时长。

## 5. 动作-反应单元

- 镜头设计的基本单元：**一个动作（引发变化的事件）+ 一个反应（事件对世界的影响）**。
- 常用变体：标准型（动作→反应）、反应前置型（先给结果再揭示原因）、动作并置型（多个动作→总反应）、反应省略型（动作→硬切留白）、动作隐藏型（动作只存在于声音）、反应延迟型、同步型（同画面）、反应链型、链式衔接型（上一组的反应兼下一组的动作）。
- 配比：约 70% 常规 / 30% 出彩；出彩镜头平均比常规镜头略长（约 4.9s vs 4.1s）。
- 用途：一镜装不下时，优先拆成“动作镜 + 反应镜”，而不是把内容硬塞进一个镜头。

### 5.1 出彩设计（那 30% 具体怎么做）

六种主要手法（按出现频率）：

1. **视觉隐喻**（约 38%）：一个具象画面承载抽象含义（空墙光影 = 空洞感）。
2. **视角反转 / 揭示**（约 22%）：改变观众对已知信息的理解。
3. **结构呼应 / 闭环**（约 12%）：与全片另一处精确呼应，含义因中间发生的事而改变。
4. **感官对比 / 并置**（约 9%）：反差元素同画或相邻，让观众自己完成判断。
5. **信息延迟 / 留白**（约 9%）：刻意不给想知道的信息，制造悬挂。
6. **视觉奇观 / 升华**（约 3–4%）：全片累积后的终极画面。

使用纪律：

- 出彩镜头前后 82% 是常规镜头；**连续出彩不超过两个**。
- 出彩镜头平均比常规稍长（约 4.9s vs 4.1s），需要停留时间。
- 每场至少 1 个出彩设计，且落在叙事目的最重的镜头上。
- 配比按类型：叙事驱动 6–10%；结构/作者型可到 30%；概念型 15–23%。
- “好看”不是理由；“用俯拍让人显得被困住”才是。

## 6. 判据与失败形态

| 症状 | 判据 | 修法 |
|---|---|---|
| 空 / 假循环 | 信息层数 < 时长 ÷ 3 | 砍时长，或补一层信息 |
| 挤 / 动作糊成一团 | 信息层数（含“动作+台词”双层）> 时长 ÷ 2.5 | 拆拍、合并成连续链、或加时长 |
| 最后一拍被截断 | 最后一个时间标记距结尾 < 3 秒 | 把标记提前 |
| 中段赶时间 | 节拍数超出时长预算 | 减到“时长 ÷ 2.5”左右 |
| 走神 | 单镜 >15 秒且无内部变化 | 加运动/焦点/光线变化，或拆镜 |
| 动作只做一半 | 没写终态，或时间不够 | 写显式终态，并给足时间 |

## 7. 三模型时间机制差异（容量通用，机制各异）

| 模型 | 单次时长 | 时间控制机制 | 注意 |
|---|---|---|---|
| Seedance 2.0 | 4–15s | 只认镜头序号，不写精确秒数 | 不要把秒级标记写进来 |
| Seedance 2.5 | 4–30s | 整数秒时间标记；从 0 连续、总和 = duration、最后标记距结尾 ≥3s；精度为节奏级 | 标记是近似，卡帧靠后期 |
| Wan 3.0 | 2–30s | 2–5 秒/段硬骨架；首尾相接、不跳段、总和 = duration | 分段时间范围属于创作内容，可以写 |
| 其他/未知 | 先问 | 先确认是否支持秒级控制 | 不硬套任何方言 |
