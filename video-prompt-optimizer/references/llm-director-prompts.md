# 上游导演提示词（LLM / 图片模型）

> 这些是**给大语言模型或图片模型**的提示词，不是视频模型方言。
> 用途：小说转剧本、剧本转分镜、全剧视觉规范、参考片反推、原创改编、资产图。
> 写完后再交给视频层（`scenario-*` + 模型方言）。

## 1. 小说/故事转竖屏短剧剧本

```text
你是一名顶级竖屏短剧编剧，精通标准影视剧本格式、竖屏节奏与爆款逻辑。
请阅读我提供的小说/故事，把它改编成 1.5–2 分钟的竖屏短剧第 1 集。

要求：
1. 严格标准剧本格式：【场次】【地点】【时间】【人物】【动作】【台词】。
2. 不添加原著没有的情节；可删支线、合并场景、调整顺序。
3. 前 3 秒必须有强钩子；结尾留一个观众想追的悬念。
4. 对白短、口语、有潜台词；不要长篇解释。
5. 单镜时长 3–5 秒；空镜 1–3 秒；单镜不超过 10 秒。
6. 保留主线冲突、人物关系、关键台词；符合平台过审。

输出：
- 本集一句话 logline
- 本集结构（钩子/建立/升级/转折/高潮/悬念）
- 完整剧本
- 结尾悬念说明
```

## 2. 剧本转分镜脚本

完整版：

```text
你是一名顶级短剧导演。请严格基于我提供的剧本，创作电影级分镜脚本。

固定格式：
镜号 / 时长 / 景别 / 角度 / 运镜 / 焦段 / 光影 /
画面内容（环境、天气、人物肢体、面部、微表情、道具）/
表演（核心动作 + 衣物/头发跟随 + 微表情）/
台词（情绪标注）/ 音效 / 特效 / 负面控制 / 参考素材。

节奏铁律：
1. 开头 3 秒强钩子。
2. 常规叙事/对白 3–5 秒；情绪铺垫 4–5 秒；空镜 1–3 秒。
3. 绝对禁止单镜超过 10 秒。

画面要求：
1. 三层动态：核心肢体动作 + 衣物/头发跟随 + 微表情；杜绝站桩。
2. 场面调度：一前一后、高低差、突然靠近、侧身避让、肢体拉扯。
3. 空镜只用于开场交代/情绪留白/转场，内容与剧情强相关。

约束：
- 100% 贴合原剧本，不新增/删减剧情。
- 描述使用模型可理解的影视术语。
- 沿用已定的 Visual Bible。
```

精简版：

```text
以导演身份，把剧本转成分镜表。每镜：镜号/时长/景别/角度/运镜/画面/表演/台词/音效/特效。
节奏：3 秒钩子；对白 3–5 秒；空镜 1–3 秒；单镜不超 10 秒。
人物必须有三层动态，禁止站桩；空镜必须服务剧情；100% 贴合原剧本。
```

## 3. 全剧视觉规范（Visual Bible）

```text
你担任影视美术总监 + 摄影指导。根据这份剧本，制定全剧统一视觉规范。

基础规格：竖屏 9:16，真人影视写实质感；色调与光影贴合剧情；拒绝高饱和艳色。
输出：
1. 全局风格基调：画风、气质、画面路线（一句话）。
2. 色卡：主色/辅色/情绪色；给 HEX/RGB。
3. 光影体系：主光方向、色温、对比、风格。
4. 影视相机与画质参数：摄影机、镜头、光圈、色彩科学、分辨率、肤质控制。
5. 正邪/阵营视觉区分：正派色温、反派色温、法术/特效色。
6. 环境气候规则：固定地点/天气/时间的光影逻辑。
7. 通用负面提示词：画面崩坏、水印、文字、失真等。

只输出视觉规范，不拓展世界观和剧情。
```

固定前缀示例：

```text
竖屏 9:16，8K 超高清，中画幅相机，f/2.8，85mm 定焦，
ARRI 色彩科学，RAW 直出，保留皮肤毛孔与伤痕，
写实冷峻东方剑道玄幻，低饱和冷色调，电影级光影层次。
```

## 4. 参考片反推（剧本逆向工程）

```text
你是一名好莱坞商业竖屏短剧编剧 + 影视剧本分析师。
我将上传一段参考视频。不要只总结剧情，要做“剧本逆向工程”。

第一部分：基础信息
类型、目标市场、目标用户、商业定位（Female Fantasy Romance / Dark Romance / Billionaire Romance 等）。

第二部分：逐镜头解析
每个镜头：时间 / 镜头类型（Close-up / Medium / Wide / POV / Over Shoulder）/
画面 / 人物 / 动作 / 表情 / 情绪 / 环境 / 重要视觉信息 / 镜头目的。

第三部分：人物
角色名（不确定就按身份命名）/ 年龄 / 身份 / 外貌 / 性格 /
当前目标 / 隐藏目标 / 关系 / 冲突 / 魅力来源。

第四部分：剧本重构
TITLE / EPISODE / GENRE / SCENE / INT-EXT / LOCATION / TIME /
ACTION / DIALOGUE（英文 + 中文）/ EMOTION / VISUAL NOTES / ENDING HOOK。

第五部分：对白恢复
按口型、动作、情绪、上下文恢复英文对白；不要直译中文；用美剧自然表达；
不确定标 [Estimated Dialogue]；区分“画面明确出现”和“推测”。

第六部分：短剧结构
开场 Hook / 第一秒吸引点 / 为什么继续看 / 核心情绪 / 关系 / 冲突 /
最大悬念 / 结尾 Cliffhanger。

第七部分：商业分析
为什么可能爆：情绪幻想、女性爽点、男性角色吸引力、关系张力、
类型市场价值、付费点、留存原因。

第八部分：反向生成
要复制：故事结构、人物关系模型、情绪模型、开场 Hook、Cliffhanger。
不要复制：人物名、版权元素、原对白、原场景。
提炼成原创创作公式。
```

## 5. 原创改编（70% 原创）

```text
你是欧美竖屏短剧 IP 开发顾问。基于我提供的剧本，开发一部全新原创短剧。

第一阶段：提取爆款结构（先不改编）
核心商业类型 / 核心观众幻想 / Hook / Character Fantasy /
Relationship Engine / Conflict Engine / Mystery Engine / Episode Engine /
情绪节奏（EP1 钩子、EP2–3 关系、EP4–6 升级、EP7–9 秘密、EP10–12 反转）。

第二阶段：原创化策略
原创比例 ≥70%；允许借鉴类型结构/情绪模型/节奏/关系张力；
禁止复制人物名、身份、剧情事件、对白、场景。

第三阶段：3 个原创方向
每个：TITLE / GENRE / ONE LINE HOOK / CORE FANTASY /
MAIN DIFFERENCE / TARGET AUDIENCE / COMMERCIAL POTENTIAL / AIGC 可行性。

第四阶段：完整故事
Logline / 类型定位 / 核心冲突 / 人物关系 / 12–24 集故事弧 /
分集地图（每集 Hook / 冲突 / 情绪节拍 / 揭露 / Cliffhanger）。

第五阶段：本土化审核
像欧美原创剧吗？人物行为符合欧美文化吗？女性角色有主动性吗？
男性角色是否只是霸总模板？对白自然吗？有中国短剧痕迹吗？有版权相似风险吗？
“只是换皮”就继续改。
```

## 6. 资产图提示词

### 6.1 人物定妆照

```text
电影级角色定妆照，正面中景，纯白/高级灰无缝背景。
【年龄/性别/身份/气质】；【脸型/五官/眼睛/眉毛/鼻子/嘴唇】；
【发型/发色/发质】；【服装/材质/配饰】。
真实皮肤质感：毛孔、轻微色素不均、自然纹理、哑光、无油光、无塑料感、无过度磨皮。
柔和的影视定妆光，正面主光 + 弱补光；真实眼神光。
85mm 人像镜头，浅景深，电影级调色，真实演员质感。
负面：油光、玻璃肌、塑料皮肤、AI 脸、网红妆、过度锐化、CG 感。
```

### 6.2 人物多视图

见 `consistency-and-assets.md` 第 2 节（6 种版式）。

### 6.3 道具设计图

```text
专业影视道具资产设计图（Prop Design Sheet），纯白背景，无人物、无场景。
包含：正面全比例图、侧面结构图、45° 立体图、关键局部放大、结构分解图。
【尺寸标注】【结构/材质/颜色/细节】【特殊符号/纹样】。
【设计气质】【视觉风格】【摄影与表现】。
负面：人物、手持、战斗、场景、血迹、现代元素、游戏 UI、塑料材质。
```

### 6.4 场景资产

```text
【题材/风格】场景设计，电影级环境概念。
场景名称 / 时代 / 地点 / 空间结构 / 建筑 / 材质 / 环境 / 天气 / 时间 / 光线 / 色彩 / 氛围。
空间构图：前景/中景/左侧/右侧/远景。
摄影：广角/焦段/机位/景深。
光影：主光/色温/体积光。
材质：真实材质/哑光/无塑料 CG。
负面：现代元素、游戏场景、廉价 CG、过度装饰。
```

### 6.5 俯视结构图 / 九宫格

见 `consistency-and-assets.md` 第 3 节。

## 7. 交给视频层

1. 先用本文件生成剧本/分镜/视觉规范/资产。
2. 再用 `scenario-*` 定场景结构。
3. 再用 `visual-language.md` 补景别/运镜/色彩。
4. 最后读模型方言写视频提示词。
5. 不要把 LLM 提示词里的 `{{...}}` 占位符原样提交给视频模型。

## 8. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 剧本加戏 | 模型自由扩写 | 明确“不添加原著没有的情节” |
| 分镜站桩 | 没写三层动态 | 强制核心动作+跟随+微表情 |
| 视觉不统一 | 没先定 Visual Bible | 先出规范再出分镜 |
| 参考片复述 | 只总结剧情 | 按镜头拆；区分明确/推测 |
| 原创变换皮 | 只改名字 | 70% 原创；本土化审核 |
| 资产不可用 | 没有多角度/尺寸 | 加多视图、结构图、局部放大 |
| 占位符残留 | 直接提交 | 按目标模型替换 |
