# 场景路由

> 只决定“写什么结构”，不写模型语法。选定场景后，再读命中的模型方言。
> 一次只读一份场景配方；跨场景时先写主场景，再叠加第二场景，并说明顺序。

## 1. 五个场景

| 场景 | 用户会怎么说 | 配方 | 默认结构 | 关键检查 |
|---|---|---|---|---|
| TVC / 广告 | 品牌片、产品片、卖点、60/30/15 秒、产品登场 | `scenario-tvc.md` | 策略一句话 → 3 创意方向 → 视觉记忆点 → 产品登场 → 品牌落点 | 产品是否清楚、卖点是否可证、品牌是否落地 |
| 竖屏短剧 | 1.5–2 分钟一集、3 秒钩子、结尾悬念、海外短剧 | `scenario-short-drama.md` | 钩子 → 冲突升级 → 转折 → 悬念收尾 | 前 3 秒、单镜 ≤10 秒、结尾是否想追 |
| 动作 / 打戏 | 30 秒 10 镜、对打、特效、环境破坏 | `scenario-action.md` | 开场碰撞 → 追击 → 贴身 → 升级 → 终极对拼 | 双方区分、攻防可追踪、特效绑定动作 |
| 对话 / 情绪戏 | 双人对白、微表情、站位、反应镜头 | `scenario-dialogue-emotion.md` | 建立 → 反应 → 台词 → 反应 → 落点 | 情绪外化、站位写死、反应镜头 |
| 蒙太奇 / 节奏 | 平行、交叉、重复、隐喻、空镜、40/60/90–120 秒 | `scenario-montage.md` | 两条线关系 → 镜头并置 → 母题重复 → 落点 | 镜头之间是否产生新意义、删线测试 |

## 2. 选场景前先问自己

1. 这条片子**卖什么/讲什么**？（产品、故事、情绪、观点）
2. 观众**看完要记住什么**？（卖点、人物、反转、视觉奇观）
3. **时长**是多少？（15/30/60/90–120 秒）
4. 是**单镜**还是**多镜**？多镜之间靠什么连接？（因果、并置、重复、对比）
5. 有没有**现成资产**？（角色图、场景图、道具图、参考片）
6. 目标模型是哪个？（先不写，最后落到方言）

## 3. 组合规则

一个任务命中两个场景时：

| 组合 | 顺序 | 例子 |
|---|---|---|
| 短剧 + 动作 | 先短剧（钩子/冲突/悬念），再动作（打戏结构） | 第 1 集结尾一场打戏 |
| TVC + 蒙太奇 | 先 TVC（策略/产品登场），再蒙太奇（并置/对比） | 60 秒品牌片的多线叙事 |
| 情绪戏 + 动作 | 先情绪（关系/潜台词），再动作（冲突爆发） | 双人对峙后动手 |
| 短剧 + 蒙太奇 | 先短剧（本集结构），再蒙太奇（回忆/对比） | 回忆杀与现在交叉 |

规则：

- 主场景决定**整体结构**；第二场景只处理**局部段落**。
- 不要把两份配方的节拍表硬拼成一张；先写主结构，再在对应段落标注“这里用动作/蒙太奇写法”。
- 组合超过两个场景时，先拆成多个镜头段落，逐段路由。

## 4. 没有命中场景时

用通用结构：

```text
主体 + 场景 + 动作 + 运镜 + 光影 + 风格 + 声音 + 约束
```

如果用户只给一句模糊需求：

1. 先问“这条片子要卖什么/讲什么/让观众记住什么”。
2. 再问时长与画幅。
3. 仍不明确时，按 15 秒通用短片写一版，并说明假设。

## 5. 场景配方与模型层的交接

每份场景配方只写到“镜头表/节拍表/资产清单”为止。交接给模型层时：

1. 先确认目标模型与任务类型。
2. 读命中的模型方言。
3. 把镜头表翻译成该模型的语法（时间戳/镜头序号/分句/符号）。
4. 用模型参考的检查清单再过一遍。

**禁止**：把场景配方里的结构词（如“钩子”“产品登场”“平行蒙太奇”）直接当模型指令；模型只认它自己的语法。

## 6. 场景不明确时的提问

只问会改变结构的问题：

- “这条是品牌/产品广告，还是剧情短片？”
- “主要给谁看？看完要记住什么？”
- “是单镜情绪，还是多镜叙事？”
- “有没有参考片/参考图？”

不要问“你想要什么风格”这种非阻塞问题；先给默认，再让用户改。
