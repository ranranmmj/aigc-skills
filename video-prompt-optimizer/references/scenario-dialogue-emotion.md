# 对话 / 情绪戏场景

> 模型无关。先写表演、站位与镜头关系，再落到模型方言。
> 核心：**情绪必须外化成可见细节；对话必须有反应镜头；站位必须写死。**

## 1. 先问清楚

| 问题 | 要拿到什么 |
|---|---|
| 谁和谁 | 人物、关系、权力差 |
| 这场戏要什么 | 信息、情绪、关系变化、决裂/和解 |
| 潜台词 | 嘴上说什么、心里想什么 |
| 台词 | 逐字内容、说话人、语言、画内/画外 |
| 空间 | 地点、左右、距离、遮挡、光线 |
| 结尾 | 谁占了上风、关系变成什么 |

## 2. 情绪外化

不要只写“悲伤/愤怒/开心”。把情绪拆成可见细节：

| 部位 | 可写细节 |
|---|---|
| 眼睛 | 眼神方向、聚焦/失焦、眨眼频率、眼眶泛红、泪未落 |
| 眉毛 | 微皱、上扬、压低、颤动 |
| 嘴角 | 下压、上扬、抿紧、轻微抽动 |
| 手 | 攥紧、松开、摩挲、悬停、指尖发抖 |
| 身体 | 前倾/后仰、肩膀塌下/绷紧、重心转移、后退半步 |
| 呼吸 | 变浅、变重、屏住、长呼气 |
| 声音 | 音量、语速、停顿、气声、颤抖 |

示例：

- 不写“她很悲伤”。
- 写“她低头看着照片，指尖在边缘停住，肩膀轻轻塌下，眼眶泛红但没有落泪，呼吸变浅”。

## 3. 站位与调度

写死四件事：

1. **位置**：画面左/中/右、前景/中景/背景。
2. **朝向**：面对镜头/侧身/背对/面向对方。
3. **距离**：一臂、一步、隔着一张桌子、约 1.5 米。
4. **遮挡/高低差**：谁挡谁、谁坐着谁站着、谁在门内门外。

常用调度：

- 过肩镜头：从一人肩后看另一人，制造对话参与感。
- 正反打：A 说 → B 反应 → B 说 → A 反应。
- 高低差：站/坐、楼梯、床边，制造权力差。
- 突然靠近/后退：关系变化。
- 侧身避让：回避/拒绝。
- 前景遮挡：用门框/柱子/人群制造距离。

## 4. 镜头模式

一场双人戏的最小结构：

```text
建立：中景/全景交代两人位置与距离
反应：A 说话前/后，B 的微表情
台词：A 的台词，近景/过肩
反应：B 的反应，特写/近景
转折：谁靠近/后退/转身/沉默
落点：一个动作或一句短台词
```

要求：

- 每句关键台词前后至少给一个反应镜头。
- 不要一个机位从头拍到尾。
- 特写只给情绪转折点；不要全片特写。
- 沉默也是戏：停顿、呼吸、手部动作。

## 5. 台词与节奏

- 台词时长按角色语速“演一遍”估算（见 `timing-and-beats.md`）；一句长台词拆成 2–3 句，中间给反应。
- 台词要短、口语、有潜台词；不要解释背景。
- 情绪写在台词前的表演里，不要靠括号堆形容词。
- 不要台词时写“无台词”，用动作/环境声完成叙事。
- 对白语言统一；非中文台词标明语言。

## 6. 对白处理武器库

同一段对话有十几种拍法；按“权力关系 / 情感暗流 / 信息载体”选，不要默认正反打。

### 正反打变体

- **标准过肩**：保持空间关系，最常用。
- **脏框**（dirty single）：前景角色局部入画、不对焦，多一层在场感。
- **clean single**：画面只有说话者，制造孤立感。
- **渐进推近**：随情绪升温从中景推到近景，景别推近 = 情感推近。

### 非正反打

- **双人不切**（two-shot）：两人同框，让观众自己看谁。
- **拍听者不拍说者**：台词的重量由反应传达。
- **侧面平行**：两人并排面朝同一方向，亲密或回避。
- **背影 / 后脑勺**：隐藏内心、说谎，或话比脸重要。
- **空间介入**：对话中穿插环境空镜，给对话加注脚。
- **镜面 / 反射**：通过镜子、玻璃对话，看到的不是“真人”。
- **遮挡 / 窥视**：门缝、窗后拍，偷听者的位置。
- **长镜走位**：不剪辑，用角色移动代替剪辑。
- **全景远观**：看得到说不到，画面比内容重要。
- **空镜承载对白**：完全不拍说话的人，声画分离改变台词含义。

### 选择逻辑

1. **权力**：平等 → 双人镜头；压制 → 景别或角度差异。
2. **情感**：对抗 → 正反打推近；回避 → 侧面或背影；亲密 → 不切；沉淀 → 空镜。
3. **信息载体**：在说者嘴里 → 拍说者；在听者反应里 → 拍听者；在空间气氛里 → 拍环境。

## 7. 潜台词写法

| 表面 | 潜台词 | 写法 |
|---|---|---|
| “你走吧。” | 我希望你留下 | 她说着“你走吧”，手却抓住他的袖口，没有松开 |
| “我没事。” | 我有事 | 他笑着说“我没事”，低头把药瓶塞进抽屉 |
| “恭喜你。” | 我恨你 | 她举杯说“恭喜你”，嘴角在笑，眼神没有温度 |

写潜台词时，**动作与台词相反**，观众就能读到两层。

## 8. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 木头人 | 只写情绪词 | 外化成眼神/眉毛/嘴角/手/呼吸 |
| 站桩对白 | 一个机位念完 | 正反打/过肩/反应镜头/走位 |
| 情绪过火 | 大哭大喊 | 克制：泪未落、手抖、呼吸变浅 |
| 没有关系变化 | 两人各说各的 | 写清谁靠近/后退/沉默/占上风 |
| 台词太长 | 一段话塞一镜 | 拆句；按角色语速演一遍估时；中间给反应 |
| 口型不齐 | 没写口型/音色绑定 | 台词句绑定音色；写口型同步；生成后核对 |
| 观众看不懂 | 没有反应镜头 | 每句关键台词后给反应 |

## 9. 交给模型层

- 2.0：动作写细、情绪外化、镜头序号；台词用该模型的符号。
- 2.5：动作概括、一个节拍一个动作、时间戳；不要重复外貌。
- Wan 3：2–5 秒/镜、台词句与音色参考同句、口型同步。
- 通用模型：按 `generic-video-model.md` 问清台词/口型/音频支持。

## 10. 示例（结构）

```text
场景：深夜厨房，妻子等丈夫解释。
站位：妻子在画面左，背对水槽；丈夫在画面右，站在门口，距离约两步。
建立：中景，两人一左一右，中间隔着餐桌。
A（妻子，背对）："你今晚去哪了？"
反应：丈夫的手指在门框上停住，没有立刻回答。
B（丈夫）："加班。"
反应：妻子关掉水龙头，水声停；她没有转身。
A："你衬衫上有香水味。"
转折：丈夫向前半步，又停住；妻子终于转身。
落点：她看着他，没有哭；他把视线移开。
```
