# Wan 3.0 方言

> 适用：`wan3.0-video` / `wan3.0-video-prime`
> 核对：2026-10-30（阿里云百炼官方 Prompt 指南 + API 参考 + 官方 wan3-pe）
> **只读这一份。** 不要同时读 Seedance 2.0 / 2.5 的参考，也不要把它们的语法带进来。

## 一句话原则

Wan 3.0 用**中文自然指令 + 七段式公式**；分镜靠“序号 + 时间戳 + 2–5 秒/段”的硬骨架，台词、音效、BGM 都有自己的一套语法。

> 时长容量、拍的定义、每段该装多少信息、台词怎么估时长，见 `timing-and-beats.md`（模型无关）；本文件只写 Wan 3 的方言语法。

## 五条红线

1. 分镜每段 **2–5 秒**，首尾相接、不跳段、不重叠；不切镜就写“生成单镜头 / 一镜到底”。
2. 素材编号按上传顺序，图片/视频/音频**分开计数**；官方写法是 `图1 / 视频1 / 音频1`。
3. 台词写成“角色 + 说 + ： + 引文”，逐字保留；不要台词必须显式写“无台词 / 全片无台词”。
4. 声音层不能空着：环境音、动作音、BGM 至少给一句明确态度；不要 BGM 写“无背景音乐”。
5. 负向清单只在用户明确要排除时写，3–8 项，不凑数、不重复正向；能用正向状态锁定就正向写。

## 能力边界

| 能力 | 规格 |
|---|---|
| 单次时长 | 2–30 秒，或 `-1` 智能时长；默认 5 秒 |
| 参考素材 | 图片 ≤10、视频 ≤5（总长 ≤15s）、音频 ≤5（总长 ≤15s） |
| 首帧 / 首尾帧 | 各 1 张；与参考素材**互斥** |
| 文件 / 网页 | 各 1 个；file 与 link 互斥；必须公网可访问 |
| 提示词长度 | ≤20,000 字符；超了会被截断 |
| 分辨率 | 1080P（默认）/ 720P / 480P |
| 宽高比 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive（默认） |
| 音频 | 默认 `audio=true`；首帧/首尾帧模式不能带音频 |
| 帧率 | 默认 30fps |
| 智能改写 | `prompt_extend` 默认 true，会先用大模型改写提示词 |
| 视频编辑 / 延长 | 需要 `reference_video`；编辑/延长意图靠提示词关键词判断 |

## 官方七段式公式

```text
提示词 = [总体描述]
       + [参考素材引用：图 N / 视频 N / 音频 N]
       + [分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制]
       + [台词：xx 说："xxxx"]
       + [音效 / BGM]
       + [风格 / 情绪]
       + [负向清单]
```

官方原话：**“想控制什么就写上，写不到的板块直接跳过。”** 一句话也能成片，但描述越完整越贴近预期。

### 可选：给下游 PE 的整理稿（wan3-pe 五段式）

只有用户明确要“整理稿 / 给下游 PE 用 / 先别写成片提示词”时才用。官方 `wan3-pe` 的五段式：

```text
[Core Task]
<题材/类型 + 成片概述 + 素材参考关系 + 全局风格>

[Plot Summary]
1. <情节节点一：人物、动作、事件；台词逐字绑定说话人>
2. <情节节点二……>

[Audio Style]
<对白语言与质感、现场音效、音乐情绪与节奏>

[Camera & Core Constraints]
<镜头风格、运动、剪辑节奏、用户给的硬约束>

[Negative Prompts]
<用户明确排除的内容；没提就省略>
```

规则：

- `[Core Task]` 与 `[Plot Summary]` 总是输出；`[Audio Style]` 和 `[Camera & Core Constraints]` 按用户输入详细程度决定；`[Negative Prompts]` 只在用户明确要排除时出现。
- 整理稿只整理用户已有的剧情、主体、台词和参考要求，**不替用户扩写剧情**。
- 素材引用集中在 `[Core Task]`；每个素材写清采用什么、范围是什么。
- 时间戳按用户原文保留；用户没写就只保留节点编号。
- **整理稿不是最终提示词**；要投喂模型时，再用七段式公式写一版，两者不要混在同一份输出里。

## 按形态选公式

### 文生视频（T2V）

```text
主体 + 场景 + 运动
```

不够就上进阶：

```text
主体 + 场景 + 运动 + 美学控制 + 风格化 + 音效
```

- 主体：人、动物、植物、物品，或想象物体。
- 场景：主体所处环境，含背景与前景。
- 运动：具体运动 + 非主体的运动状态；写幅度、速率、作用效果。
- 美学控制：光源、光线环境、景别、视角、镜头、运镜。
- 风格化：赛博朋克、勾线插画、废土、宋式写实等。
- 音效：背景音效、BGM、台词、旁白，可描述音色。

### 首帧 / 首尾帧

```text
运动 + 运镜
```

首帧图像已经确定主体、场景与风格，所以**只写动态过程与运镜**，不要复述外观。
希望镜头不动就写“固定镜头”；有运镜要求就写“镜头推进 / 左移 / 环绕”。

### 参考生视频

```text
参考对象 + 动作 + 台词
```

参考对象写 `图1 / 视频1 / 音频1`；同一素材可在不同位置多次引用，分别控制形象、动作、音色、场景。
参考图已经承载外观时，不再复述长相、发型、服装。

### 多镜头

```text
总体描述 + 镜头序号 + 时间戳 + 分镜内容
```

详见下一节。

### 视频编辑（V2V）

```text
编辑对象 + 编辑行为
```

只写要改的地方，不要重述全片；想保住其余部分就加“其他保持不变”。

## 参考素材

- 官方写法：`图1`、`视频1`、`音频1`；`图片1` 与 `图1` 等价。
- 编号按上传顺序，图片/视频/音频**分开计数**；所以图1和视频1可以同时存在。
- 只有 1 个素材时可简写“参考图片”“参考视频”；2 个及以上必须写编号。
- 同一素材可多处引用：形象、动作、音色、场景各引一次。
- 单素材示例：`参考图片，生成它奔跑的视频`；`参考视频的运镜方式，重拍一段`。
- 锁形象：`图1的儿童站在图2的现代公寓玄关内`。
- 只借色调：`仅参考图2的色调与光影，不参考人物`。
- 音色：`音色参考音频1`；`按音频1的音色说："xxxx"`。
- 文档/网页：`根据我的提案文档，生成一支品牌广告片`；`根据王维的百科词条，生成一支一年级科普动画`。

> **口径说明**：官方文档（2026-10）用 `图1 / 视频1 / 音频1`，**不带 `@`**。部分社区 skill 用 `@图片1`，官方文档没有这个前缀。本 skill 默认按官方写法；如果你的平台/工作流已验证 `@图片1` 更稳，可整条统一替换，但不要在同一条里混用。

## 分镜与时间戳

```text
提示词 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容
```

- 总体描述：一句话说明主题、视角、叙述风格、整体情绪。
- 镜头序号：给每个镜头编号，定义顺序。
- 时间戳：紧跟序号标起止时间；每段 **2–5 秒**，首尾相接，不跳段、不重叠。
- 分镜内容：主体动作、台词、表情、场景细节；避免高频不可控动作（如“一秒摇头 3 次”）。

格式不拘，但要通篇统一；`[起-止]` 与 `（起-止）` 通用：

| 写法 | 示例 |
|---|---|
| 序号 + 时间戳 | `分镜1[0-3秒] xxxx`、`第1个镜头[0-3秒]：xxxx`、`分镜1（00:00-00:03）：xxxx` |
| 只标序号 | `镜头1：xxxx；镜头2：xxxx` |
| 只标时间戳 | `[00:00-00:03] xxxx` |

三个高频控制项：

- 单镜头：首行写 `生成单镜头` / `一镜到底`。
- 镜头不动：`固定镜头，摄影机静止，机位不变`。
- 运镜：用大白话（推近/拉远/环绕/手持跟拍），不要堆专业术语。

转场写在段末或下段开头：`硬切转场`、`叠化转场`，或“从上一分段的最后一帧无缝衔接”。
节奏写进总体描述：`节奏由沉稳压抑转为爆发`、`全片八个镜头，节奏轻快铺垫、突发冲突、短促爆发、温暖收尾`。

## 台词

- 格式：`角色 + 说话动词 + 冒号 + 引号`。例：`图1说："xxxx"`；`图2回答："xxxx"`；`她低声说道："xxxx"`。
- 多人对话逐句写，点名说话人；不要只写“两人对话”。
- 音色克隆：追加 `音色参考音频1`；**写一次即对该角色全部台词生效**。
- 口型同步：追加 `口型同步` 或 `Lip sync.`。
- 画外音 / 独白：`旁白："xxxx"`；`女声吟诵："xxxx"`。
- **不要台词必须显式写** `无台词` / `全片无台词`，否则模型自行决定是否加。
- 台词逐字保留；语言按用户给的语言写。

## 声音

**自动匹配**：画面里写清动作、材质、气象（`战旗猎猎`、`鼻息白气`、`积水踩踏`），模型自动补音效。

**主动指定**：单独成句，可带时间戳：

```text
枪声音效 + 狐火粒子特效
第8秒起，女声吟诵："xxxx"
```

**BGM 三档**：

- 不写：模型自选。
- 明确指定：`BGM 转入低音区，大提琴以极轻力度缓缓加入`；`史诗交响 + 电子音效混合，节奏与镜头切换同步`。
- 完全不要：`无 bgm，只生成环境音和动作音` / `无背景音乐`。

## 风格 / 情绪

美术风格 + 色调 + 情绪三件套，可放开头或结尾；可展开，也可只给关键词。

| 段 | 关键词参考 |
|---|---|
| 美术风格 | 35mm 电影胶片 / 港式写实 / 线条插画 / 废土风格 / 宫崎骏动画 / 国风矿物色 / 黏土动画 / 动态图形 / Apple Keynote 极简商务 |
| 色调 | 高饱和暖黄 / 青蓝×鎏金对比 / 低调高反差 / 去饱和青灰对高饱和金 |
| 情绪 | 悲壮不屈 / 轻快治愈 / 压抑紧张 / 松弛自信 / 神秘奇幻 |

## 负向清单

官方公式包含 `[负向清单]`；当前 API 参数表**没有** `negative_prompt` 字段，所以负向是写在提示词正文里的。

- 只写不希望出现的内容；没有就留空。
- **不必凑数，也不要重复正向已写明的内容。**
- 建议 3–8 项，按“身份稳定 → 物理正确 → 摄影正确 → 文字与品牌 → 声音边界”挑最相关的。
- 八类参考：人物画面、文字水印、风格、声音、动作、运镜、空间、一致性。
- 避免写模型控不住的高频动作，如“一秒摇头 3 次”。

| 常见负向 | 示例 |
|---|---|
| 人物/画面 | 面部不扭曲、不换脸、不出现多余手指、肢体不扭曲、无穿模、无抠图痕迹、不低清 |
| 文字/水印 | 无字幕、无水印、无复杂文字、无额外品牌名 |
| 风格 | 不要儿童卡通、不要真人写实、不要游戏 CG 感、不要廉价赛博朋克 |
| 声音 | 无背景音乐、无旁白、无台词、BGM 不压过主体 |
| 动作 | 不要简单撕裂、不要人物无逻辑奔跑、不要夸张肢体、不要夸张眨眼、不要慢动作 |
| 运镜 | 不要大运镜、不要夸张镜头旋转、不要持续晃动、不要过度防抖、不要频繁切镜 |
| 空间 | 不要空间混乱、不要车辆穿模、不要越轴、不要多人同框 |
| 一致性 | 不要角色位置变化、不要服装变化、不要比例漂移 |

> 否定词对模型不稳定；“不要出现 X”有时反而召唤 X。能改写成正向状态就正向写：
> `不要出现文字/字幕` → `画面干净无叠加图形，纯实拍质感`；
> `不要变形` → `五官与肢体比例保持稳定自然，轮廓边缘清晰`；
> `镜头不要动` → `固定镜头，机位与焦距全程不变`。

## 特殊任务

### 故事板 / 多宫格

- 开头声明：`使用故事板作为分镜指导，禁止将故事板作为单张图像生成视频`。
- 从左上到右下逐格重述内容；**分段不必与宫格一一对应**。
- 结尾统一声明画风 + 负向清单。

### 白模渲染

- 声明“除材质与颜色外一律不改”。
- 列出“镜头轨迹 / 剪辑点 / 物体位置 / 角色动作 绝对不变”。
- 反复强调 `一帧不增删、一秒不错位`。
- 用 `真实折射 / 次表面散射` 之类光学细节提真实感。

### 线控运镜

- 图上的红线路径要在提示词里**按点位逐段复述**。
- 写明“成片完整清除所有红线、数字标号、箭头”。
- 速度分层：`快 → 慢 → 快`。

### 视频编辑

- 动词用 `增加 / 删除 / 替换 / 改成 / 重塑`。
- **一次只改一项最稳**；开头“编辑视频”可省。
- 想保住其余部分：`其他保持不变`，或点名要保留的对象。
- 改台词保音色：`保持人物音色和语气，将女生的说话内容改为："xxxx"`。

### 视频延长

- 提示词须含 `延长 / 延续 / 续写` + 方向（向前 / 向后 / 双向）。
- 从输入视频的**实际终点**写唯一新动作和新终点。
- **输入视频时长 + 输出时长 ≤30 秒**；`duration` 建议 `-1`。
- 不要重述原片已有画面，否则模型可能从头再演一遍。

### 首帧 / 首尾帧

- 与**全能参考模式互斥**；启用后不再支持参考素材输入。
- 提示词只写中间过程如何从首帧过渡到尾帧，不复述首帧已有外观。

### 文件 / 网页参考

- 上传 docx / pptx / xlsx / pdf 或网页链接，**必须公网可直接访问**（登录墙/内网读不到）。
- 提示词只交代“面向谁、什么风格、什么形式”；细化可写镜头结构、旁白节奏、数字动画。
- `prompt_extend` 必须为 true（官方要求）。

### 音频驱动

- 节拍驱动（舞蹈跟拍）或音色驱动（台词迁移）。
- 写清“跟随固定音频的节拍”+ 动作/口型同步要求。
- 首帧模式不能带音频；需要音频驱动时走全能参考模式（`reference_image` + `reference_audio`）。

## 参数与提示词联动

| 参数 | 取值 | 备注 |
|---|---|---|
| `duration` | 2–30 或 `-1` | 默认 5；有视频输入时，输入+输出 ≤30s |
| `ratio` | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive | 默认 adaptive；想锁竖屏必须传参数，不要写“竖屏” |
| `resolution` | 1080P / 720P / 480P | 默认 1080P |
| `audio` | true / false | 默认 true，开关同价 |
| `prompt_extend` | true / false | 默认 true；会改写提示词，可能改掉逐字台词/声音层 |
| `seed` | 0–2147483647 | 复现用；同 seed 也不保证完全一致 |
| `watermark` | true / false | 默认 false |

- 参数只用于规划，不写进正文；**Wan 3 的分镜时间范围是创作内容，可以写**。
- 逐字台词、声音层、镜头数很重要时，显式把 `prompt_extend` 关掉，或生成后逐项核对。
- 成本先估：1080P 约 1.2 元/秒，10 秒 ≈ 12 元；批量前先跑小样。

## 常见故障 → 修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 人物换脸 / 跨镜不一致 | 参考图质量、编号、复述外观 | 每个角色 1–2 张清晰正面/侧面图；按上传顺序编号；不要复述长相；固定 seed |
| 双胞胎 / 多出一个人 | 多人同框、参考图过多 | 明确人数；单人单图；必要时分组；负向写“不出现外形完全一致的人物” |
| 台词被截断 | 台词时长超出镜头容量 | 按角色语速“演一遍”估算（见 `timing-and-beats.md`）；超了拆段 + 加衔接锚点，或加时长、删句 |
| 口型对不上 | 没写口型同步或音色参考位置不对 | 台词句后加“口型同步”；音色参考与说话动作同句；生成后逐镜核对 |
| 出现字幕 | 模型自行加 | 写“画面干净无字幕叠加”；参考图先修掉文字；不要依赖负面词 |
| 出现 BGM | 声音层空着 | 写“无背景音乐”；开头结尾各写一遍；穷举同义词 |
| 室内下雨 | “湿地/反光/雨夜”等触发词 | 写“室内干燥整洁、地面干爽无积水”；雨只限定在窗外；想要反光写“打磨光滑的木地板反射微光” |
| 空间/朝向错 | 没写死位置与朝向 | 写画面左/中/右、朝向、距离；躺卧写头脚方向；≥3 人先分区 |
| 道具握反 | 用相对方位描述 | 用功能命名（手柄/剑柄/发光端/枪管）；两端都给方向；写握姿；结尾加一致性声明 |
| 任务被判成别的类型 | 编辑/延长关键词不清 | 编辑用“增加/删除/替换/改成”；延长写“向前/向后延长、延续、续写”；参数同步 |
| 剧烈物理交互穿帮 | 打斗、破碎、泼洒等弱项 | 拆两段（起势/结果）、换局部视角、或写清肢体数量与接触后形态；先提醒风险 |
| 开场角色看镜头 | 默认摆拍感 | 开场写“四分之三侧身、视线锁定对手/目标物、不看向镜头” |
| 硬切跨镜漂移 | 跨镜一致性无自动保证 | 每个分镜开头复述角色标识；结尾写跨镜一致性约束；场景锚点；固定 seed；切点落在句号或静默处 |
| 动作只做一半 | 模型回归擅长画面 | 写显式终态（“箱盖完全掀起竖立、露出内部”）并给足 3–4 秒 |
| 文本审核被拦 | 文本绿网，非画面问题 | 软化触发词或如实告知用户；不要用画面级补丁治文本级拦截 |

## 交付前检查清单

- [ ] 是否明确写了分镜时间段，且每段 2–5 秒、首尾相接、总和 = duration？
- [ ] 不切镜时是否写了“生成单镜头 / 一镜到底”？
- [ ] 素材编号是否按上传顺序、分类型计数？是否与素材清单一致？
- [ ] 有参考图时是否还在复述长相/发型/服装？（应删）
- [ ] 台词是否逐字保留、说话人明确、不要台词时写了“无台词”？
- [ ] 音色参考是否与说话动作同句？需要口型时是否写了“口型同步”？
- [ ] 声音层是否完整？不要 BGM 是否写了“无背景音乐”？
- [ ] 负向清单是否 3–8 项、不凑数、不重复正向？
- [ ] 是否把 `ratio / resolution / audio` 写进了正文？（应移到参数）
- [ ] 编辑/延长是否只写增量、没有重述全片？
- [ ] 首帧/首尾帧是否与参考素材混用？（互斥）
- [ ] 文件/网页是否公网可访问、`prompt_extend=true`？
- [ ] 重要逐字台词是否考虑关闭 `prompt_extend` 或生成后核对？

## 禁止从 Seedance 带入

- `@图片N` 作为默认指代（官方是 `图1`；社区变体另说，一条内只用一种）。
- `{}` 台词、`<>` 音效、`（）` 音乐、`【】` 字幕这套符号。
- “不写时间戳、只用镜头序号”的 2.0 习惯。
- 2.5 的“四段式”标题、`omni_reference_task_type`、`draft`、`output_format=mov` 参数。
- 把 `ratio` 写进正文（如“竖屏 9:16”）；Wan 3 靠参数锁画幅。

## 示例

**多镜 + 参考 + 台词 + 音色**

```text
东方古典写实，冷灰与湿褐色调，宋式审美，电影级真实质感。
图1是少妇（严格参考面部、发型、服装、年龄、体型），图2是暴雨中的竹藤桥（锁定结构、材质、低矮贴水状态），音频1是少妇音色。
整体节奏由压抑转为危急，全片四个镜头，硬切转场，固定机位与手持跟拍结合。

第1个镜头[0-3秒]大全景，90°垂直俯拍，固定机位。竹桥横贯画面左右，洪水从画面上方向下方高速冲击，少妇位于桥中部破损区域，一只手撑伞，另一只手把襁褓抱在胸前。
第2个镜头[3-6秒]近景，水面平视，镜头缓慢横移。竹桥中段突然失去支撑，少妇脚下踩空，油纸伞脱手被狂风翻转后落水；她的第一反应是把襁褓往胸口收紧，两只前臂向内夹住孩子，脸从茫然转为惊恐。
第3个镜头[6-9秒]中近景，微俯，手持跟拍。少妇半个身体挂在断桥外，腰部以下浸入湍急河水，一只手死死抓住横向竹杆，另一只手把襁褓托在肩膀以上。少妇说："救救孩子！"，音色参考音频1，口型同步，声音发抖、语速急促。
第4个镜头[9-12秒]面部近景，微俯，轻微横摇跟随。王六郎从水面探出半个头，雨水打在湿发和脸上；他没有明显表情，眼睛跟随少妇移动，随后头部转向对岸，身体沉下一点，快速向同一方向游去。

音效为暴雨、洪水轰鸣、竹桥断裂、麻绳绷断、油纸伞落水、急促喘息；无背景音乐。
画面干净无字幕叠加；人物面部与身体比例稳定；少妇严格只有两条手臂、两只手；竹桥结构与位置全程不变。
负向清单：不要第三只手、不要多余手臂、不要断肢、不要面部扭曲、不要双胞胎、不要字幕、不要水印、不要现代元素。
```

> `图1` 是官方写法；如果你的平台已验证 `@图片1` 更稳，可整条统一替换，不要混用。
