# 一致性与资产

> 模型无关。一致性不是一句“保持不变”，而是一套资产 + 参考 + 空间锚点的系统。
> 本文件含**图片模型/LLM 的前置提示词**，不是视频模型方言；写完再交给视频层。

## 1. 先判断缺什么

| 症状 | 可能缺的资产 |
|---|---|
| 人物换脸/漂移 | 角色定妆照、三视图/多视图、表情库 |
| 场景漂移 | 场景原图、俯视结构图、九宫格/全景 |
| 站位翻转 | 站位参考图、标注图、俯视调度图 |
| 道具握反/变形 | 道具设计图、握持锚点、朝向声明 |
| 画面脏/噪点 | 修图/超清/线稿+深度重构 |
| 跨镜不连 | 尾帧、首帧、空间锚点、同 seed |

缺资产时，先补资产提示词，不要在视频提示词里硬写“保持一致”。

## 2. 人物多视图（6 种版式）

图片模型提示词占位符用 `{{参考图N}}`；按你的图片模型替换。

### 2.1 左大头 + 右三视

```text
生成一张人物全身三视图。最左边是超大正面面部特写；右侧放全身正面、侧面、背面三视图，
放在一张图里。纯白色背景（人物服装偏白时用高级灰背景）。标准头身比例，成年人约 7.5 头身，
拒绝 1:1 身材，人体结构协调自然。保持同一张脸、同一发型、同一套服装。
```

### 2.2 左全身三视图 + 右四特写

```text
以 {{参考图1}} 作为唯一角色参考，生成同一角色的多视图角色设定表。
保持角色身份完全一致：相同脸型、五官比例、发型、服装、配饰、身体比例，不改变任何设计细节。
16:9 横版，纯白背景，专业角色资产排版。
左侧：全身正面/45°侧面/背面三视图，标准站姿。
右侧：正面脸部特写、45°左脸、45°右脸、90°侧脸。
所有视角来自同一个角色；清晰展示脸部结构、发型、服装细节。
```

### 2.3 特写面部 + 全身四视图（两张图）

第一张：面部细节特写（控制脸）。
第二张：全身四视图（正面/前侧/纯侧/背面，1×4 网格）。

```text
第一张：{{参考图1}} 的人物面部细节特写，真实皮肤纹理、毛孔、眼神、发丝。
第二张：同一人物全身四视图，正面/前侧面/纯侧面/背面，1×4 网格排版，
高级灰背景，标准头身比例，同一张脸、同一套服装。
```

### 2.4 上特写 + 下全身（2×2，不带脸）

```text
生成同一角色的 2×2 角色资产板。上半部分两张：面部细节特写 + 半身姿态；
下半部分两张：全身正面 + 全身背面（不带清晰脸，避免抢身份）。
纯白背景，统一光线，同一服装/发型/体型。
```

### 2.5 表情库

```text
以 {{参考图1}} 作为唯一角色参考，生成同一角色的表情与情绪表演库。
保持五官结构、脸型、发型、服装、年龄不变；只改变面部肌肉与情绪状态。
16:9 横版，纯白背景，专业角色表情设计表，整齐排列。
表情：自然、开心微笑、悲伤低落、愤怒、惊讶、严肃冷静、害羞温柔、坚定决绝。
每个表情保持同一张脸；清晰展示眼神、眉毛、嘴部、面部情绪细节。
```

### 2.6 艺术身份板

```text
创建一张 16:9 艺术性角色身份板。使用 {{参考图1}} 作为主体。
纯白/米白背景，无环境、无道具、无水印。
布局不对称、优雅、有留白；避免网格/目录感。
主视觉：一个大型全身英雄视角，略偏离中心。
周围：中性全身、背面、侧面、坐姿、倾斜、蹲姿、俯视、仰视、表情研究；每个视角清晰分离，不重叠。
身份锁定：相同面部、比例、发型、服装、身体比例、姿势语言。
可加小轮廓研究、小表情研究、小细节研究、极简角色 ID 块。
风格：电影感、高端、艺术书、干净、可用于制作。
```

## 3. 场景一致性（4 种方法）

### 3.1 人物资产 + 原图 + 俯视图（最常用）

1. 根据剧本生成单张场景图。
2. 用场景图生成俯视结构图（90° 垂直俯视，无透视，保留布局）。
3. 视频参考：人物资产 + 场景图 + 俯视图；写清人物在空间中的位置。

俯视图提示词：

```text
根据 {{参考图1}}，生成电影级场景结构蓝图（Cinematic Scene Structure Blueprint）。
90° 垂直俯视，无透视；精准还原空间结构、比例关系、区域布局、主要环境元素。
添加简洁影视美术标注：主要物体、设施、出入口、观察窗、功能区域、重要视觉节点。
保持原布局，不新增元素；不要添加摄影机、人物路线、动作路径和分镜信息。
```

### 3.2 场景九宫格（多机位）

```text
参考 {{参考图1}}，生成同一室内场景的影视多视角设定图。
保持原场景设计、空间关系、家具、材质、色彩和整体风格一致。
16:9 横版，3×3 九宫格整齐排列，每个画面下方加简洁机位名称。
包含：正面全景、左前 45°、右前 45°、后方视角、斜俯视、门正面方向，
以及 3 个有代表性的空间细节视角。同一场景，多机位，统一视觉风格，专业场景设定板。
```

### 3.3 720° 全景

- 基于单张场景图生成 720° 全景，截取所需背景。
- 优点：方便；缺点：背面视角不一定符合预期，需要提前规划。
- 适合 LibTV 重度用户；不适合对背面精度要求高的镜头。

### 3.4 完整空间布局图 + 单场景（高精度）

1. 先让 LLM 生成完整空间布局（房间/建筑/道路/出入口/人物动线）。
2. 依据布局图生成各场景图。
3. 视频参考：人物资产 + 场景图 + 布局图；写清空间锚点。

完整布局图提示词：

```text
根据剧本，生成一张影视美术用完整空间布局图。
白底建筑平面图，中文标注：空间名称、入口、主要家具、关键道具、人物动线。
标注人物行动路线：角色A 从 X 到 Y；角色B 从 X 到 Y。
保持空间结构合理、出入口清晰、动线不矛盾。
```

## 4. 人物站位（5 种方法）

### 4.1 提示词固定（简单两人）

```text
观众视角，角色A 在画面左侧，角色B 在画面右侧，二人对峙状态。
```

适合简单两人、位置明确；复杂多人容易漂。

### 4.2 参考图固定（多人/衔接上一镜）

- 截取上一镜中景/全景中的人物位置关系；避开近景/特写。
- 用尾帧/上一镜某帧做参考时，先超清处理，避免新画面受低画质影响。
- 提示词：`仅参考 {{参考图1}} 的人物空间站位关系；观众视角，角色A 在画面左侧，角色B 在画面右侧。`

### 4.3 标注框（大多数情况）

1. 在场景图上用不同颜色框标出每个角色位置。
2. 明确“颜色框 = 角色名”。
3. 提示词：`基于这张俯视图，女主参考红色边框位置，宗主参考绿色边框位置；生成视频中不显示边框标记。`

### 4.4 俯视图 + 人物标记（调度）

```text
基于这张俯视场景图 {{参考图1}}，生成一张俯拍调度图。
保持原房间结构不变，加入两个人物站位：女主 {{参考图2}} 坐在标记 1 床边，
宗主 {{参考图3}} 站在标记 10 的位置，面朝女主。两人之间保持清晰距离。
```

需要动线时：

```text
基于俯视场景图 {{参考图1}}，生成俯拍调度图。保持原场景结构不变，加入人物运动轨迹：
女主 {{参考图2}} 从床边站起，走到标记 4 桌子旁，用黄色箭头表示；
宗主 {{参考图3}} 在标记 10，退到标记 3 小茶几，用蓝色箭头表示。
```

### 4.5 导演台/3D 工具

- 用 LibTV 导演台等工具摆位、调机位、看动线。
- 适合多人、复杂空间、需要精确调度；日常简单场景用前四种即可。

## 5. 图片修复（3 种方法）

### 5.1 Nano Banana / 图片模型洗图

```text
画面干净、平滑，不要细碎噪点，不要高频纹理，不要密集颗粒。
保持原图构图、镜头、主体位置、建筑结构、光照方向、色彩氛围；
不新增建筑、人物、装饰；优先恢复大轮廓、大体块、连续表面，不在远处堆小点/碎纹理。
```

### 5.2 即梦超清

- 导入画布 → 超清。
- 细节程度 100：修复最强，但可能有小范围文字乱码；适合画面文字不重要。
- 细节程度 50：中等，基本保留原图，去噪点。
- 建议 50–75。

### 5.3 LibTV 线稿 + 深度图重构

1. 原图生成黑白线稿。
2. 原图生成深度图。
3. 原图 + 线稿 + 深度图重构。

提示词：

```text
以 {{参考图1}} 为主要画面基础，进行高质量写实重建。
严格保留构图比例、镜头视角、主体位置、建筑造型、光照方向、整体色彩氛围；不新增建筑/人物/装饰。
用 {{参考图2}} 的黑白线稿校正建筑结构：轮廓完整、边缘连续、透视准确、边界干净，无断裂/粘连/重影/畸变。
用 {{参考图3}} 的深度信息建立前景/中景/远景；清晰度随距离自然递减，形成空气透视。
优先恢复大轮廓、大体块、连续表面；不在远处堆小点/碎纹理/伪细节。
建筑平整稳定，结构清晰但不过度锐化；画面干净通透。
```

## 6. 资产清单

### 人物

- 定妆照（正面中景，纯白/高级灰背景）。
- 三视图/多视图（同一张脸、同一服装、同一比例）。
- 表情库（至少 6–8 个情绪）。
- 每个角色固定样音（需要台词时）。

### 场景

- 单张场景原图（24mm 广角，交代空间）。
- 俯视结构图（90° 垂直）。
- 九宫格/多机位（需要多角度时）。
- 空镜/氛围图（转场、情绪留白）。

### 道具

- 多角度设计图（正面/侧面/45°/局部）。
- 尺寸/材质/结构标注。
- 握持/朝向声明（不对称道具必须）。

### 特效

- 统一粒子/光晕/色彩规范。
- 可复用特效素材（护体灵光、剑气、魔气、结界等）。

## 7. 视频侧一致性

- **参考职责**：每个素材只负责一个主职责；同一素材多职责拆句。
- **重复锚点**：人物每次出现重复身份锚点；场景每次出现重复空间锚点。
- **跨镜约束**：结尾统一声明“同一角色/同一空间/朝向不变”。
- **同 seed**：复现/对比时固定 seed；跨镜一致性优先同 seed。
- **首尾帧**：需要严格衔接时用实际尾帧/生成尾帧，不要只写“保持一致”。
- **参考质量**：参考图分辨率不要低于输出；脏图先修。
- **数量控制**：参考不是越多越好；人物 1–2 张关键图优先。

## 8. 交给模型层

1. 先补齐资产；没有资产就先出资产提示词。
2. 再写视频分镜/镜头表。
3. 最后读模型方言，把资产编号、参考职责、一致性约束翻译成该模型语法。
4. 不要把图片提示词的占位符（如 `{{参考图1}}`）原样提交给视频模型；按视频模型规则替换。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 换脸 | 参考图不足/不清晰 | 补定妆照 + 多视图；重要参考前置 |
| 双胞胎 | 多视图 + 主体不清 | 单人单图；明确人数；加一致性约束 |
| 场景漂移 | 没有结构图 | 补俯视图/九宫格/全景 |
| 站位翻转 | 没写左右/朝向 | 写死位置/朝向/距离；用标注图 |
| 道具握反 | 用相对方位 | 功能命名 + 两端方向 + 握姿 |
| 脏图/噪点 | 原图质量/分辨率 | 洗图/超清/线稿+深度 |
| 跨镜不连 | 没有锚点/尾帧 | 加空间锚点、尾帧、同 seed |
| 参考太多反而乱 | 素材职责不清 | 一素材一职责；减少数量 |
