# 视听语言

> 模型无关。把“我想要什么感觉”翻译成“景别/角度/构图/运镜/色彩/镜头”。
> 这些词进入提示词时，仍要按目标模型的方言组织。

## 1. 五大景别

| 景别 | 画面范围 | 情绪作用 | 提示词写法 |
|---|---|---|---|
| 远景 | 广阔环境，人物很小 | 交代时间/地点/氛围；孤独、渺小、史诗 | 大远景 / 广角全景 / 环境建立镜头 |
| 全景 | 人物全身 + 环境 | 动作与空间关系；客观、完整 | 全景，人物全身入画 |
| 中景 | 膝部以上 | 叙事最常用；动作、手势、关系 | 中景，过肩/双人 |
| 近景 | 胸部以上 | 聚焦表情与情绪；“拟神” | 近景，面部表情清晰 |
| 特写 | 肩部以上或局部 | 放大细节、制造冲击 | 特写 / 极近特写 / 微距 |

口诀：**远景写意，全景写实，中景叙事，近景拟神，特写点睛。**

用法：

- 开场用远景/全景交代；不要一上来就特写（除非钩子需要）。
- 对话用中景/近景/过肩；关键情绪用特写。
- 产品广告：极近特写给材质，大空间给品牌高度。

## 2. 拍摄角度

| 角度 | 感觉 | 用法 |
|---|---|---|
| 平视 | 平等、客观、中立 | 大多数对话 |
| 俯视 | 渺小、弱势、被控制 | 反派被击败、人物无助 |
| 仰视 | 高大、有力量、压迫 | 英雄登场、权威 |
| 过肩 | 主观代入、对话参与 | 双人对话 |
| 贴地 | 神秘、危险、速度 | 追逐、怪物视角 |
| 鸟瞰 | 审判感、全局 | 开场、命运感 |

角度是情绪的快捷键；同一句话，俯拍和仰拍是两种意思。

## 3. 构图

| 构图 | 作用 | 写法 |
|---|---|---|
| 居中 | 稳定、仪式、压迫 | 人物居中，对称 |
| 三分 | 生动、自然、留白 | 人物放在三分线/交点 |
| 对角线 | 动感、不安、冲突 | 人物/道路沿对角线 |

广告常用：

- 大空间：品牌高度。
- 极近特写：产品价值。
- 人与产品关系：情绪连接。

## 4. 五种基础运镜

| 运镜 | 效果 | 情绪 | 提示词写法 |
|---|---|---|---|
| 固定 | 镜头不动，主体动 | 稳定、客观、真实 | 固定镜头，画面稳定 |
| 推 | 慢慢靠近主体 | 聚焦、紧张、期待 | 缓慢推镜头，聚焦主体 |
| 拉 | 慢慢远离主体 | 揭示环境、失落、揭晓 | 缓慢拉镜头，展现完整环境 |
| 摇 | 机位不动，左右/上下转 | 扫视、第一人称、展示空间 | 缓慢横摇镜头 |
| 跟 | 跟着主体移动 | 跟随、代入、动态 | 跟随镜头，主体始终居中 |

要求：

- 一个镜头只给一种主运镜；不要推拉摇移同时上。
- 运镜要有动机：跟随人物、揭示信息、制造压迫；不要为了动而动。
- 固定镜头不是“没运镜”，是“让主体动”。

## 5. 色彩心理

| 颜色 | 情绪 | 常见用法 |
|---|---|---|
| 红 | 激情、紧迫、危险 | 冲突、警告、爱情 |
| 蓝 | 冷静、专业、信任 | 科技、医疗、孤独 |
| 绿 | 自然、健康、生机 | 环保、治愈、毒性（偏黄绿） |
| 黄 | 温暖、活力、乐观 | 家庭、童年、警示（偏暗黄） |
| 黑 | 高端、神秘、力量 | 奢侈品、反派、仪式 |
| 白 | 纯净、简约、高级 | 护肤、医疗、极简 |

写法：

- 不要只写“冷色调”；写“冷蓝低饱和、青灰、暖黄 practical 光”。
- 一部片只保留一个主色关系；不要每镜换色。
- 用色彩做对比：冷环境 + 暖人物光；黑白场景 + 一点红。

## 6. 镜头焦段

| 焦段 | 空间/情绪 | 用法 |
|---|---|---|
| 24–35mm | 广角、空间感、环境关系 | 建立镜头、动作、史诗 |
| 50mm | 接近人眼、真实关系 | 对话、日常 |
| 85mm | 浅景深、人物肖像、压缩空间 | 情绪特写、产品细节 |
| 100mm+ | 微距/极浅景深 | 材质、细节、窥视 |

写法：`35mm 电影镜头，浅景深`、`85mm 人像镜头，背景虚化`；不要只写“电影感”。

## 7. 意图 → 视觉词

| 想要 | 可以写 |
|---|---|
| 孤独 | 大远景，小人，冷蓝，负空间 |
| 压迫 | 仰拍，广角，人物占满画面，硬光 |
| 脆弱 | 俯拍，浅景深，柔光，手部特写 |
| 紧张 | 手持，近距离，短焦，快速推 |
| 释然 | 缓慢拉远，暖光，开阔环境 |
| 危险 | 贴地，低机位，冷硬光，阴影 |
| 高级 | 大空间，极近特写，85mm，低饱和，柔光 |
| 混乱 | 多人物，手持，对角线，冷暖冲突 |

## 8. 交给模型层

- 先定景别/角度/构图/运镜/色彩，再写模型提示词。
- 按模型能力简化：2.0 一镜一运镜；2.5 镜头全局写一次；Wan 3 分镜 2–5 秒；通用模型问清运镜支持。
- 不要把“电影感/高级感”当唯一描述；用具体的景别、光、焦段、色彩支撑。

## 9. 常见失败

| 症状 | 原因 | 修法 |
|---|---|---|
| 画面平 | 全是中景/平视 | 加远景/特写/俯仰变化 |
| 运镜乱 | 一镜多运镜 | 一镜一主运镜；写动机 |
| 没有重点 | 构图散 | 三分/居中/前景遮挡；明确主体 |
| 情绪不对 | 角度/景别错 | 用角度和景别重写 |
| 色彩脏 | 颜色太多 | 一个主色关系 + 一个对比色 |
| 不像电影 | 只写“电影感” | 补焦段、光位、景深、颗粒 |
| 空间乱 | 没写左右/朝向 | 位置 + 朝向 + 距离 |
